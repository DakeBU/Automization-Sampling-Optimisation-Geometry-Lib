Let E be an arbitrary finite-dimensional real inner-product space equipped with its Borel measurable structure (dimension zero is permitted). Let V:E->R be twice continuously differentiable, let alpha,beta be nonnegative reals, and let eta be real. Assume 0<alpha, alpha<=beta, 0<eta, beta*eta<=1, and, for every x,v in E,
alpha*||v||^2 <= D(DV)(x)[v][v] <= beta*||v||^2.
All inequalities involving alpha or beta as real scalars use their coercions to R.

On Omega=R^N put P=the countable product of rate-one exponential measures. Set e_k(omega)=max(omega_k,0), considered as a nonnegative real. For y,xRef in E, z=(q,p) in E x E, and real s, define
c=y-eta*grad V(xRef),
Phi(y,xRef,s,(q,p))=(c+cos(s)*(q-c)+(sqrt(eta)*sin(s))*p, (-sin(s)/sqrt(eta))*(q-c)+cos(s)*p).
For d=grad V(q)-grad V(xRef), define
S(xRef,(q,p))=(q,p-(2*<p,d>/||d||^2)*d),
rate(xRef,(q,p))=sqrt(eta)*max(0,<p,d>).
Division is the total real division of the literal Lean definitions; at d=0 the correction in S is zero.
For t>=0 set Lambda(y,xRef,z,t)=integral from 0 to t of rate(xRef,Phi(y,xRef,s,z)) ds, and define tau(y,xRef,z,e) as the infimum in nonnegative reals with infinity adjoined of {u>=0: Lambda(y,xRef,z,u)-e>=0}, with infinity when this set is empty.

For a nonnegative sequence e and initial z0 in E x E define records R_n in (R_nonnegative x (E x E)) disjoint-union Unit. Start with R_0=inl(0,z0). A stopped record inr remains inr. From R_k=inl(s,z), if tau(y,xRef,z,e_k)=infinity put R_(k+1)=inr; otherwise, writing w for this finite wait, put R_(k+1)=inl(s+w,S(xRef,Phi(y,xRef,w,z))). The code extracts w by untopD 0 only in the finite branch; its value zero at infinity is not used to make a live update. Define T_n as the stored time of a live record and infinity for a stopped record.

For every fixed y,xRef in E and every fixed z0 in E x E, for P-almost every omega, BOTH of the following hold, with records and times generated using e(omega):
(1) For every finite t>=0 there exists exactly one natural number n such that T_n<=t<T_(n+1).
(2) For every finite t>=0 and every natural n, if T_n<=t<T_(n+1), there exists exactly one a=(s,z) in R_nonnegative x (E x E) such that R_n=inl(a), s<=t, and the finite nonnegative elapsed time t-s, embedded into the extended nonnegative reals, is strictly less than tau(y,xRef,z,e_n).
The subtraction t-s in (2) is NNReal subtraction, which is truncated in general; the asserted s<=t makes it ordinary nonnegative elapsed time. An infinite next wait is allowed and every finite elapsed time is strictly below it. A stopped record has T_n=infinity and cannot satisfy T_n<=finite t. Equal adjacent event times make an empty half-open interval; strict wait positivity is not an assumed premise or separately stated conclusion. The full-measure event can depend on y,xRef,z0: the statement does not put their universal quantifiers inside one common almost-everywhere event. No law of a random initial state, no global interpolated process, and no measurable selector is asserted.
