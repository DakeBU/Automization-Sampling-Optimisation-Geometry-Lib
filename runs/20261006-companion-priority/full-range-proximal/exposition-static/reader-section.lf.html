Complete source statement (Samplinglib restatement)

Produce a measurable exact proximal selector p satisfying p+eta*gradientV(p)=y, the genuine quantitative quadratic minimum and uniqueness, and fixed-eta nonexpansivity. The literal Gaussian gradient evaluator G(s,z)=gradientV(p(s)+sqrt(eta(s))*z) is jointly measurable and obeys input/noise Lipschitz constants 1 and sqrteta for equal eta. Produce an actual Markov kernel K(s)=stdGaussian.map(G(s,-)). This covers the exact evaluator (3.2) and only Lemma4.2 (4.4)-(4.5), with no posterior or finite-query claim.

  • Source beta=1, alpha=kappa^-1, real kappa>=1; actual C2 V with kappa^-1*normv^2 <= D2V(x)[v,v] <= normv^2 for every x,v.
  • Finite real complete Hilbert/Borel full space E, including dimension zero; arbitrary measurable parameter space S; actual measurable eta:S->R and y:S->E with 0<eta(s)<=1 for every s. These coordinate-free/parameter-space extensions are disclosed.
  • No supplied proximal point, minimizer, measurable selector, gradient estimate, Lipschitz bound or Markov kernel. All are produced from the literal potential and actual Gaussian pushforward. The source numerical-prox call cap eta<=1/(2beta) remains a separate computational contract.

Proof roadmap

  1. 1Derive the real gradient estimates

    Reuse the actual C2 Hessian-to-gradient and strong-convexity APIs. The source upper bound supplies gradientV Lipschitz1. The convex gradient-step theorem supplies id-gradientV Lipschitz1, and convexity supplies monotonicity. None is a theorem premise.

  2. 2Construct a uniformly damped map

    Use a real sufficient implementation of the source-implicit proximal existence step. For each actual parameter, damp the equation by (1+eta)^-1. Its contraction factor is eta/(1+eta)<=1/2 throughout 0<eta<=1, including eta1. This is a mathematical construction, not a numerical query-cost assertion.

  3. 3Obtain joint measurability from actual iterates

    Start every iteration at zero. Actual measurable eta/y and the continuous id-gradient map make every parameterized iterate measurable. Banach convergence and measurable limit prove measurability of the actual selector, rather than assuming a measurable choice.

  4. 4Recover the exact source equation

    Multiply the actual fixed-point equation by positive 1+eta and cancel the scalar inverse. The resulting equality is the literal proximal first-order condition for the source quadratic potential.

  5. 5Prove the genuine minimum and uniqueness

    Differentiate the true quadratic regularization. Its gradient vanishes at the constructed p. Existing strong-convexity and first-order bounds give the exact coefficient (kappa^-1+eta^-1)/2. Positivity forces norm(z-p)^2=0 for any competing lower point.

  6. 6Keep nonexpansivity at fixed eta

    Subtract the two literal proximal equations only when eta_s=eta_t. Monotonicity bounds the inner product below by the squared proximal distance. Cauchy-Schwarz and positive-norm cancellation give nonexpansivity; a zero-distance branch is handled separately.

  7. 7Use the literal Gaussian gradient evaluator

    The actual measurable p, eta square root and noise coordinate give a jointly measurable input to the continuous gradient. No posterior identification or oracle witness is used.

  8. 8Prove the exact input and noise constants

    Apply the true gradient Lipschitz bound, split the input difference with the triangle inequality and use proximal nonexpansivity at equal eta. The literal square-root coefficient stays outside the noise norm. This supplies both source inequalities (4.4)-(4.5).

  9. 9Realize the actual Markov kernel

    Take the product of the identity kernel and the constant standard Gaussian kernel, then map it by G. Joint measurability proves it Markov; dirac-product and map-map give the exact pointwise pushforward. This gradient-output law is distinct from the RGO posterior and HMC transitions.

    [CompleteSpace E] [FiniteDimensional ℝ E] [MeasurableSpace E] [BorelSpace E]
    [MeasurableSpace S] {V : E → ℝ} {κ : ℝ}
    (hκ : 1 ≤ κ) (hV : ContDiff ℝ 2 V)
    (hH : ∀ x v : E, κ⁻¹*‖v‖^2 ≤ fderiv ℝ (fderiv ℝ V) x v v ∧
      fderiv ℝ (fderiv ℝ V) x v v ≤ ‖v‖^2)
    {eta : S → ℝ} {y : S → E} (heta : Measurable eta) (hy : Measurable y)
    (hpos : ∀ s, 0 < eta s) (hsmall : ∀ s, eta s ≤ 1) :
    let F := fun s x => V x + (eta s)⁻¹/2*‖x-y s‖^2
    ∃ p : S → E, Measurable p ∧
      (∀ s, p s + eta s • gradient V (p s) = y s) ∧
      (∀ s z, F s (p s) + (κ⁻¹+(eta s)⁻¹)/2*‖z-p s‖^2 ≤ F s z ∧
        (F s z ≤ F s (p s) ↔ z=p s)) ∧
      (∀ s t, eta s = eta t → ‖p s-p t‖ ≤ ‖y s-y t‖) ∧
      let G := fun q : S × E => gradient V (p q.1+Real.sqrt (eta q.1) • q.2)
      Measurable G ∧
      (∀ s t z w, eta s = eta t →
        ‖G (s,z)-G (t,w)‖ ≤ ‖y s-y t‖+Real.sqrt (eta s)*‖z-w‖) ∧
      ∃ K : ProbabilityTheory.Kernel S E, ProbabilityTheory.IsMarkovKernel K ∧
        ∀ s, K s = (ProbabilityTheory.stdGaussian E).map (fun z => G (s,z))

theorem full_range_proximal_gaussian_oracle
    {E S : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E]
    [CompleteSpace E] [FiniteDimensional ℝ E] [MeasurableSpace E] [BorelSpace E]
    [MeasurableSpace S] {V : E → ℝ} {κ : ℝ}
    (hκ : 1 ≤ κ) (hV : ContDiff ℝ 2 V)
    (hH : ∀ x v : E, κ⁻¹*‖v‖^2 ≤ fderiv ℝ (fderiv ℝ V) x v v ∧
      fderiv ℝ (fderiv ℝ V) x v v ≤ ‖v‖^2)
    {eta : S → ℝ} {y : S → E} (heta : Measurable eta) (hy : Measurable y)
    (hpos : ∀ s, 0 < eta s) (hsmall : ∀ s, eta s ≤ 1) :
    let F := fun s x => V x + (eta s)⁻¹/2*‖x-y s‖^2
    ∃ p : S → E, Measurable p ∧
      (∀ s, p s + eta s • gradient V (p s) = y s) ∧
      (∀ s z, F s (p s) + (κ⁻¹+(eta s)⁻¹)/2*‖z-p s‖^2 ≤ F s z ∧
        (F s z ≤ F s (p s) ↔ z=p s)) ∧
      (∀ s t, eta s = eta t → ‖p s-p t‖ ≤ ‖y s-y t‖) ∧
      let G := fun q : S × E => gradient V (p q.1+Real.sqrt (eta q.1) • q.2)
      Measurable G ∧
      (∀ s t z w, eta s = eta t →
        ‖G (s,z)-G (t,w)‖ ≤ ‖y s-y t‖+Real.sqrt (eta s)*‖z-w‖) ∧
      ∃ K : ProbabilityTheory.Kernel S E, ProbabilityTheory.IsMarkovKernel K ∧
        ∀ s, K s = (ProbabilityTheory.stdGaussian E).map (fun z => G (s,z)) := by
  let F := fun s x => V x+(eta s)⁻¹/2*‖x-y s‖^2
  obtain ⟨hLip,hMinus,hsc,hmono⟩ := actual_gradient_bounds hκ hV hH
  obtain ⟨p,hp,heq⟩ := parameterized_damped_point hMinus heta hy hpos hsmall
  have hmin := actual_quadratic_minimum hκ hV hH hpos heq
  have hnexp : ∀ s t, eta s=eta t → ‖p s-p t‖ ≤ ‖y s-y t‖ := by
    intro s t ht
    have hsub : y s-y t=(p s-p t)+eta s • (gradient V (p s)-gradient V (p t)) := by
      rw [← heq s,← heq t,← ht]
      module
    have hpair : ‖p s-p t‖^2 ≤ inner ℝ (y s-y t) (p s-p t) := by
      calc
        _ ≤ ‖p s-p t‖^2+eta s*inner ℝ (gradient V (p s)-gradient V (p t)) (p s-p t) :=
          le_add_of_nonneg_right (mul_nonneg (hpos s).le (hmono (p s) (p t)))
        _ = _ := by
          rw [hsub,inner_add_left,real_inner_smul_left,real_inner_self_eq_norm_sq]
    have hb := hpair.trans (real_inner_le_norm (y s-y t) (p s-p t))
    by_cases hz : ‖p s-p t‖=0
    · simpa only [hz] using norm_nonneg (y s-y t)
    · have hpositive : 0 < ‖p s-p t‖ := lt_of_le_of_ne (norm_nonneg _) (Ne.symm hz)
      nlinarith
  refine ⟨p,hp,heq,hmin,hnexp,?_⟩
  let G := fun q : S × E => gradient V (p q.1+Real.sqrt (eta q.1) • q.2)
  have hG : Measurable G := hLip.continuous.measurable.comp
    ((hp.comp measurable_fst).add ((heta.comp measurable_fst).sqrt.smul measurable_snd))
  have hGLip : ∀ s t z w, eta s=eta t →
      ‖G (s,z)-G (t,w)‖ ≤ ‖y s-y t‖+Real.sqrt (eta s)*‖z-w‖ := by
    intro s t z w ht
    have h := hLip.dist_le_mul (p s+Real.sqrt (eta s) • z) (p t+Real.sqrt (eta t) • w)
    simp only [NNReal.coe_one,one_mul,dist_eq_norm] at h
    have hdiff : (p s+Real.sqrt (eta s) • z)-(p t+Real.sqrt (eta t) • w) =
        (p s-p t)+Real.sqrt (eta s) • (z-w) := by rw [← ht]; module
    calc
      _ ≤ ‖(p s+Real.sqrt (eta s) • z)-(p t+Real.sqrt (eta t) • w)‖ := h
      _ = ‖(p s-p t)+Real.sqrt (eta s) • (z-w)‖ := by rw [hdiff]
      _ ≤ ‖p s-p t‖+‖Real.sqrt (eta s) • (z-w)‖ := norm_add_le _ _
      _ ≤ ‖y s-y t‖+Real.sqrt (eta s)*‖z-w‖ := by
        rw [norm_smul,Real.norm_eq_abs,abs_of_nonneg (Real.sqrt_nonneg _)]
        exact add_le_add (hnexp s t ht) le_rfl
  let K := (Kernel.id ×ₖ Kernel.const S (stdGaussian E)).map G
  have hK : IsMarkovKernel K := Kernel.IsMarkovKernel.map _ hG
  have hKs (s : S) : K s=(stdGaussian E).map (fun z => G (s,z)) := by
    dsimp only [K]
    rw [Kernel.map_apply _ hG,Kernel.prod_apply,Kernel.id_apply,Kernel.const_apply,
      Measure.dirac_prod,Measure.map_map hG (by fun_prop)]
    rfl
  exact ⟨hG,hGLip,K,hK,hKs⟩
