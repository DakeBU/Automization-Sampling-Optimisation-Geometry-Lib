For every natural number d, with an explicit proof argument hd witnessing 2 ≤ d; for every real number κ, with an explicit proof argument hκ witnessing 2 ≤ κ; and for every matrix O in the full real orthogonal group on the d coordinates, make the following local definitions.

The coordinate indices are i ∈ Fin d, with natural values i.val = 0, …, d − 1. Set
  θ(i) = ((i.val as a real number) + 1/2) π / (d as a real number),
  A = O diag(i ↦ (κ + 1)/2 + ((κ − 1)/2) cos(θ(i))) Oᵀ.
Let E = EuclideanSpace ℝ (Fin d), identified with ℝ^d with its usual real Euclidean inner product. Define, for x ∈ E,
  f(x) = ((WithLp.ofLp x) · (A (WithLp.ofLp x))) / 2,
  query(x) = WithLp.toLp 2 (A (WithLp.ofLp x)).
The maps WithLp.ofLp and WithLp.toLp 2 preserve the vector coordinates, so these formulas say f(x) = xᵀAx/2 and query(x) = Ax in ordinary coordinates. The orthogonality assumption is OᵀO = OOᵀ = I and permits either determinant sign.

Then for every x ∈ E both of the following assertions hold:
1. HasGradientAt f (query(x)) x: f is genuinely real Fréchet differentiable at x, with derivative the linear functional h ↦ ⟨query(x), h⟩, for h ∈ E.
2. The ordered-pair identity
     (f(x), gradient f x) = (⟨x, query(x)⟩ / 2, query(x))
   holds.

Here gradient f x denotes the inverse Riesz image of the totalized real Fréchet derivative fderiv ℝ f x, with the stated zero fallback where a derivative does not exist. Assertion 1 is an explicit conjunct, so assertion 2 is accompanied by genuine differentiability at the same x. The symbols θ, A, f, and query are the local definitions above, not additional universally quantified inputs. E is only explanatory notation for the displayed Euclidean space, and h is bound only within the derivative description.
