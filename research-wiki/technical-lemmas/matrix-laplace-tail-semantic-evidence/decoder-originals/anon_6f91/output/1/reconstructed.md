# 匿名 packet 1：独立数学重构

## 对象 / objects

给定同一概率实验上的实随机方阵 \(X\)。记 \(n=|\iota|\)，于是 \(X(\omega)\) 是 \(n\times n\) 矩阵。其矩阵指数使用通常的矩阵乘法：
\[
e^{sX(\omega)}=\sum_{m=0}^{\infty}\frac{s^m X(\omega)^m}{m!},\qquad X(\omega)^0=I_n.
\]
这里 \(\operatorname{tr}A=\sum_{i\in\iota}A_{ii}\)，没有除以 \(n\)。对任一矩阵 \(A\)，令
\[
\Lambda(A)=\sup_{\mathbb R}\{\lambda\in\mathbb R:\lambda I_n-A\text{ 不可逆}\},
\]
其中这个上确界严格取 Lean 中实数条件上确界 `sSup` 的意义。

## 定义域 / domains

\(\Omega\) 是任意类型，带一个可测空间结构；\(\mu\) 是其上的概率测度。\(\iota\) 是有限、非空且有可判定相等关系的任意指标类型，故 \(n\ge1\)。\(X:\Omega\to\mathbb R^{\iota\times\iota}\)。阈值 \(t\in\mathbb R\)，变换参数 \(s\in(0,\infty)\)。方阵空间的拓扑是所给的欧氏算子范数拓扑。概率和最后的比较在扩展非负实数 \([0,\infty]\) 中进行。

## 量词 / quantifiers

对每个这样的 \(\Omega\)、可测空间结构、\(\mu\)、\(\iota\)、\(X\) 以及下面两项假设的见证，并对每一个实数 \(t\)，下述结论成立。结论右侧的下确界遍历全部严格正实数 \(s\)，不只遍历某个选定序列，也不声称下确界由某个 \(s\) 取得。类型宇宙仅决定载体所在层级。

## 输入假设、可推性质与未给定内容 / assumptions

输入假设是：\(\mu(\Omega)=1\)；\(X\) 对 \(\mu\) 几乎处处强可测，即它与某个强可测函数几乎处处相等；并且 \(X(\omega)^T=X(\omega)\) 对 \(\mu\) 几乎处处的 \(\omega\) 成立。有限非空指标、可判定相等关系和可测空间结构也是输入数据。

从实对称性可推得：几乎处处的实谱有限、非空，\(\Lambda(X(\omega))\) 是最大的代数特征值；矩阵指数的迹在这些点为正。它们不是额外的输入假设。输入没有要求 \(X\) 可积、指数矩可积、正半定、均值为零、独立，亦未要求处处对称。

## 结论 / conclusion

对任意 \(t\in\mathbb R\)，
\[
\mu\{\omega:t\le\Lambda(X(\omega))\}
\le
\inf_{s>0}\left[
 e^{-st}\int_{\Omega}^{+}
 \max\!\left\{\operatorname{tr}\left(\sum_{m=0}^{\infty}\frac{s^mX(\omega)^m}{m!}\right),0\right\}\,d\mu(\omega)
\right].
\]
这里 \(\int^+\) 是非负 Lebesgue 积分，值允许为 \(+\infty\)。这精确展开了 RHS 中两个 `ENNReal.ofReal`：\(e^{-st}>0\)，故外面的标量变换不改变它；迹的变换取其实数非负部分。等价地，在忽略对称性不成立的零测集之后，左侧是最大代数特征值至少为 \(t\) 的概率，右侧的积分是指数迹的非负期望。未断言该期望有限，也未提供更进一步的数值估计。

## 作用域及含义 / scopes-senses

所有事件、几乎处处条件及积分均相对于同一个 \(\mu\)。几乎处处对称并不把 \(X\) 在异常零测集上的实际取值替换掉：字面事件在这些点仍使用 \(\Lambda=sSup\) 的定义；这些点不改变其测度。在对称点，最大特征值没有取绝对值，亦不是谱半径或算子范数。阈值条件为包含端点的 \(t\le\Lambda\)，且允许 \(t\le0\)。右侧是先对每个 \(s\) 积分再对 \(s>0\) 取下确界。指数中的 \(sX\) 是实标量与矩阵的逐项标量乘法，而幂和指数中的乘法是矩阵乘法。没有 `let` 或布尔分支需要额外解释。

## 常数依赖 / constant-dependencies

该陈述没有待选择的常数，也没有显式额外维数因子。\(n\) 通过矩阵大小及未归一化迹进入右侧。对固定的概率空间与 \(X\)，每个待估阈值 \(t\) 有自己的 \(\inf_{s>0}\)；允许所选近似最优 \(s\) 依赖 \(t\)、\(X\) 的分布及维数，但没有断言最优参数存在。所有固定数值均已在指数、迹和积分的定义中显示。
