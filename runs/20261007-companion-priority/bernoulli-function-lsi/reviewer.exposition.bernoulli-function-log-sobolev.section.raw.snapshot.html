Mathematical statement

For every finite n including zero and arbitrary signed real h on all Boolean coordinates, normalized counting measure is probability and all three integrals are genuine L1; homogeneous entropy of h squared is at most half the expectation of the unnormalized sum of full coordinate-flip squares.

\[\mu_n=2^{-n}\sum_{\varepsilon\in\{0,1\}^n}\delta_\varepsilon,\qquad\operatorname{Ent}_{\mu_n}(h^2)\le\frac12\mathbb E_{\mu_n}\sum_{j=1}^n(h(\varepsilon)-h(\varepsilon^{(j)}))^2.\]

Proof roadmap

  1. 1Use the actual finite law

    Construct probability from normalized counting measure and actual cardinal2^n. Finite Bochner integrability is derived, and Fin.snoc gives the true balanced last-coordinate integral decomposition.

  2. 2Exact entropy chain

    Let g(x)=sqrt((h(x,+)²+h(x,-)²)/2). Expanding both sides under the same finite law gives an equality: the last-coordinate two-point entropy plus the entropy of g². No conditional entropy bound is assumed.

  3. 3Genuine RMS contraction

    The reverse two-dimensional Euclidean norm inequality yields the squared difference bound for g across each retained coordinate. Its proof derives the Cauchy-Schwarz cross term from (ad-bc)²≥0 and actual sqrt square identities.

  4. 4Integrate the two bounds with the exact energy split

    Use the signed two-point theorem for the last coordinate and induction for g. Summing the RMS contraction and splitting the actual full-flip energy gives the same half constant. For n=0 there is one state, zero entropy and no energy.

theorem bernoulli_function_logSobolev (n : ℕ) (h : (Fin n → Bool) → ℝ) :
    let μ : Measure (Fin n → Bool) :=
      (Fintype.card (Fin n → Bool) : ℝ≥0∞)⁻¹ • Measure.count
    let D := fun ε : Fin n → Bool =>
      ∑ j : Fin n, (h ε - h (Function.update ε j (!ε j))) ^ 2
    IsProbabilityMeasure μ ∧
      Integrable (fun ε => (h ε) ^ 2) μ ∧
      Integrable (fun ε => (h ε) ^ 2 * Real.log ((h ε) ^ 2)) μ ∧
      Integrable D μ ∧
      ((∫ ε, (h ε) ^ 2 * Real.log ((h ε) ^ 2) ∂μ) -
        (∫ ε, (h ε) ^ 2 ∂μ) * Real.log (∫ ε, (h ε) ^ 2 ∂μ) ≤
      (1 / 2 : ℝ) * ∫ ε, D ε ∂μ)

theorem bernoulli_function_logSobolev (n : ℕ) (h : (Fin n → Bool) → ℝ) :
    let μ : Measure (Fin n → Bool) :=
      (Fintype.card (Fin n → Bool) : ℝ≥0∞)⁻¹ • Measure.count
    let D := fun ε : Fin n → Bool =>
      ∑ j : Fin n, (h ε - h (Function.update ε j (!ε j))) ^ 2

      Integrable (fun ε => (h ε) ^ 2) μ ∧
      Integrable (fun ε => (h ε) ^ 2 * Real.log ((h ε) ^ 2)) μ ∧
      Integrable D μ ∧
      ((∫ ε, (h ε) ^ 2 * Real.log ((h ε) ^ 2) ∂μ) -
        (∫ ε, (h ε) ^ 2 ∂μ) * Real.log (∫ ε, (h ε) ^ 2 ∂μ) ≤
      (1 / 2 : ℝ) * ∫ ε, D ε ∂μ) := by
