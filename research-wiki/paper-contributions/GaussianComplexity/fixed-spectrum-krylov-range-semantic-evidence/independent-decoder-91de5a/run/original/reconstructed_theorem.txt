For all natural numbers d and q, all real kappa with kappa >= 2 and 2*q + 1 < d, and every arbitrary real Euclidean coordinate array x indexed by (i,a) with 0 <= i < d and 0 <= a <= q, set theta_i = (i + 1/2)*pi/d, lambda_i = (kappa + 1)/2 + ((kappa - 1)/2)*cos(theta_i), Lambda = diag(lambda_i), and g_a(i) = x_(i,a). For 0 <= k <= q define t_(i,k) = 1 if k = 0 and sqrt(2)*cos(k*theta_i) otherwise. Define B_(i,(a,k)) = (1/sqrt(d))*g_a(i)*t_(i,k), with ordered column index (a,k) in {0,...,q} x {0,...,q}. Then { B*c : c is any real coefficient array indexed by (a,k) } equals span_R{ Lambda^k * g_a : 0 <= a <= q and 0 <= k <= q }, as subsets of the real vectors indexed by i. All matrix-vector products use finite sums; Lambda^k denotes ordinary matrix powers, with Lambda^0 the identity, and the span contains every real linear combination. The case q = 0 is allowed, d >= 2*q + 2 >= 2 is forced, kappa = 2 and d = 2*q + 2 are included, and x may be zero or have any linear dependencies. There is no probabilistic assumption.
