# 匿名 packet 2：独立数学重构

## 对象 / objects

设 \(r=q+1\)。把输入中的全部局部定义展开如下。

样本是 \(\omega=(G_0,\ldots,G_q)\in(\mathbb R^d)^r\)，其测度为 \(r\) 个 \(d\) 维标准高斯测度的乘积。记 \(g_{b i}=(G_b)_i\)，其中 \(0\le b\le q\)、\(0\le i\le d-1\)。第 \(i\) 行向量是
\[
x_i(\omega)=(g_{0i},\ldots,g_{qi})\in\mathbb R^r,\qquad
\|x_i(\omega)\|^2=\sum_{b=0}^{q}g_{bi}^2.
\]
`WithLp.toLp 2` 和 `WithLp.ofLp` 只在这个欧氏向量和坐标函数之间转换，不改变这些坐标。定义确定量
\[
L=2r+3\log(1000d),\qquad
\alpha_i=\frac{(i+\tfrac12)\pi}{d},\qquad
v_{ik}=\begin{cases}1,&k=0,\\ \sqrt2\cos(k\alpha_i),&1\le k\le q.\end{cases}
\]
这里 \(\log\) 是自然对数。令 \(J_i(\omega)=1\) 当 \(\sum_b g_{bi}^2\le L\)，否则 \(J_i(\omega)=0\)。矩阵的行列分别用有序对 \((b,k)\)、\((c,\ell)\) 标记，且各坐标均在 \(\{0,\ldots,q\}\)。因此矩阵大小是 \(r^2\times r^2\)。其条目为
\[
(Y_i(\omega))_{(b,k),(c,\ell)}
=\frac{J_i(\omega)}{d}\,g_{bi}g_{ci}\,v_{ik}v_{i\ell}.
\]
这展开了两个外积与 Kronecker 积：第一个因子的指标是 \((b,c)\)，第二个因子的指标是 \((k,\ell)\)；截断失败时整个矩阵是零矩阵。记其无条件均值矩阵为 \(B_i\)，具体地
\[
(B_i)_{(b,k),(c,\ell)}
=\frac{v_{ik}v_{i\ell}}{d}
\int_{(\mathbb R^d)^r}J_i(\omega)g_{bi}g_{ci}\,d\mu(\omega),
\qquad Z_i(\omega)=Y_i(\omega)-B_i.
\]
这个均值是对原始、未条件化的乘积高斯测度取的 Bochner 积分。

令 \(c_i=\cos((2q+1)\alpha_i)\)，并令
\[
T(\omega)=\sum_{i=0}^{d-1}Z_i(\omega),\qquad
C(\omega)=\sum_{i=0}^{d-1}c_i Z_i(\omega).
\]
两个布尔选择给出四个矩阵，精确为
\[
S_{\mathrm{false},\mathrm{false}}=T,\quad
S_{\mathrm{false},\mathrm{true}}=-T,\quad
S_{\mathrm{true},\mathrm{false}}=C,\quad
S_{\mathrm{true},\mathrm{true}}=-C.
\]
因此第一个布尔量选择常权重 \(1\) 或余弦权重 \(c_i\)，第二个布尔量的 `true` 选择全局负号。以上条目公式及加减与实标量乘法也完全确定每个 \(S\) 的每个条目。

## 定义域 / domains

\(d,q\in\mathbb N\)，且 \(2q+1<d\)。因而 \(r=q+1\ge1\)、\(d\ge2q+2\ge2\)，并且 \(2r\le d\)。允许 \(q=0\)。输入中的 \(D\) 是 \(\mathbb R^d\)，\(E\) 是 \(\mathbb R^r\)，\(\Omega\) 是 \((\mathbb R^d)^r\)，\(M\) 是上面有序对索引的实 \(r^2\times r^2\) 矩阵空间。\(\mu=\bigotimes_{b=0}^{q}\mathcal N(0,I_d)\)。\(s\) 是严格正实数，\(a\) 是任意实数，两个布尔量各自在 \(\{\mathrm{false},\mathrm{true}\}\) 中取值。

## 量词 / quantifiers

对每一对自然数 \(d,q\) 及其不等式 \(2q+1<d\) 的见证，按上述公式构造这些对象。然后对每个实数 \(s\)，若 \(s>0\)，则对每个实数阈值 \(a\) 以及每一对布尔选择，上述相应矩阵 \(S\) 都满足下面的概率界。这是四个矩阵各自对所有 \(s>0\) 的陈述；没有取 \(s\) 的下确界，也没有选择或断言一个最优 \(s\)。

## 输入假设、可推性质与未给定内容 / assumptions

显式数值假设只有 \(d,q\) 为自然数及 \(2q+1<d\)，并在最终量词下要求 \(s>0\)。标准高斯乘积测度和截断、居中、权重、符号等均由定义给定，并非另行假设。对 \(a\) 没有正性限制。

可从这些定义推得而非另行输入的性质包括：所有 \(dr\) 个标量坐标 \(g_{bi}\) 都是相互独立的标准正态变量；\(L>0\)；每个 \(Y_i\) 处处实对称且正半定。事实上，在有序对坐标中设 \(u_{i,(b,k)}=g_{bi}v_{ik}\)，则 \(Y_i=(J_i/d)u_i u_i^T\)。截断使 \(Y_i\) 有界，故其 Bochner 均值存在且可积，\(\mathbb E Z_i=0\)；\(B_i,Z_i,T,C\) 及四个 \(S\) 均实对称。有限个有界矩阵的和仍有界，因此每个固定 \(s\) 的指数迹也可积。上述独立性、可积性、对称性和中心化均是构造的后果。

没有把截断事件作为条件来更换概率测度。没有假设或断言 \(Z_i\) 或 \(S\) 正半定，也没有给出 \(B_i\) 的显式封闭公式、方差参数的估计或进一步的尾部数值界。

## 结论 / conclusion

对于任意所述 \(d,q\)、任意 \(s>0\)、任意 \(a\in\mathbb R\)，以及四个选择中任意一个矩阵函数 \(S\in\{T,-T,C,-C\}\)，有
\[
\mu\{\omega:a\le\lambda_{\max}(S(\omega))\}
\le
\left[
 e^{-sa}\int_{(\mathbb R^d)^r}
 \operatorname{tr}\left(\sum_{m=0}^{\infty}\frac{s^m S(\omega)^m}{m!}\right)\,d\mu(\omega)
\right]_+.
\]
这里 \([z]_+=\max\{z,0\}\)，并把它视为扩展非负实数来同左侧比较。这保留了字面 `ENNReal.ofReal`，它作用于实标量乘积 \(e^{-sa}\) 与整个实积分的乘积。这里的积分是实值 Bochner 积分，而不是 `lintegral`。

矩阵指数中的 \(S^0=I_{r^2}\)，其余幂使用通常矩阵乘法；迹是 \(r^2\) 个对角元之和，没有归一化。由上述可推得的实对称性和有界性，指数迹为正且积分有限，因此这个特定构造中方括号内为正，取非负部分不会改变其值。概率界本身没有把右侧再与 \(1\) 取最小值。

## 作用域及含义 / scopes-senses

字面谱是使 \(\lambda I-S(\omega)\) 不可逆的实数 \(\lambda\) 的集合，事件采用这个集合的实条件上确界 `sSup`。由于此处 \(S(\omega)\) 处处实对称且大小 \(r^2\ge1\)，该上确界处处等于最大的代数特征值 \(\lambda_{\max}\)，没有绝对值，也不是算子范数。阈值比较为包含端点的 \(a\le\lambda_{\max}\)。截断比较也是包含端点的 \(\sum_b g_{bi}^2\le L\)。

所有均值、指数迹积分与事件概率使用同一个无条件乘积测度 \(\mu\)。每个 \(B_i\) 在选择 \(s,a\) 和布尔值之前固定。均值是先对每个单独的 \(Y_i\) 取积分，再居中，最后加权求和；全局符号乘在这个总和上。角度的指标从零开始，偏移为 \(+\tfrac12\)，余弦权重的频率是 \(2q+1\)，不属于 \(v_{ik}\) 定义中的频率范围 \(0\le k\le q\)。矩阵标量乘法逐项作用，外积、Kronecker 积及矩阵指数的乘法含义已在对象与结论中展开。

## 常数依赖 / constant-dependencies

\(r=q+1\) 仅依赖 \(q\)；\(L=2r+3\log(1000d)\) 仅依赖 \(d,q\)。其中 \(2,3,1000\) 是固定数值，\(\sqrt2\) 与 \(\pi\) 也是固定常数。\(\alpha_i\) 依赖 \(d,i\)，\(v_{ik}\) 依赖 \(d,i,k\)，其向量长度另由 \(q\) 决定。\(c_i\) 依赖 \(d,q,i\)。概率测度、\(Y_i\)、\(B_i\)、\(Z_i\)、\(T\)、\(C\) 均由 \(d,q\) 和给定公式确定，不依赖阈值 \(a\) 或正参数 \(s\)。布尔量仅选择四个现成矩阵中的一个。\(s,a\) 仅进入事件阈值或最终指数表达式。没有额外待选择的普适常数、失败概率参数或调参规则；矩阵维数因子仅通过 \(r^2\) 维的未归一化迹隐含出现。
