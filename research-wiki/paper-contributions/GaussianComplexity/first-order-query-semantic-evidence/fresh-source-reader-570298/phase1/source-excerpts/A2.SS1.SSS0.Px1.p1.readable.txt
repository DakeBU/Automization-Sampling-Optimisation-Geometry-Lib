Consider the oracle \mathcal{O}_{\mathbf{O}}(j,v,\tau):=\begin{cases}O_{j}v,&\tau=\mathsf{f},\\
O_{j}^{\top}v,&\tau=\mathsf{i},\end{cases}\qquad j\in\{1,\ldots,k\},\quad v\in\mathbb{R}^{n}. We call a query (j,v,\tau) to
this oracle a primitive query; it is forward if \tau=\mathsf{f} ,
and inverse if \tau=\mathsf{i} .
For a first-order query x=(x_{1},\ldots,x_{k},z) , we have \displaystyle A_{O_{j}}x_{j} \displaystyle=\frac{\kappa+1}{2}x_{j}-\frac{\kappa-1}{4}\bigl(\mathcal{O}_{\mathbf{O}}(j,x_{j},\mathsf{f})+\mathcal{O}_{\mathbf{O}}(j,x_{j},\mathsf{i})\bigr), \displaystyle\nabla f_{A_{\mathbf{O}}}(x) \displaystyle=(A_{O_{1}}x_{1},\ldots,A_{O_{k}}x_{k},z), \displaystyle f_{A_{\mathbf{O}}}(x) \displaystyle=\frac{1}{2}\langle x,\nabla f_{A_{\mathbf{O}}}(x)\rangle. Thus T first-order queries can be simulated using at most 2T primitive queries per block and it suffices to prove transcript
indistinguishability for adaptive primitive queries when 2T<n .
