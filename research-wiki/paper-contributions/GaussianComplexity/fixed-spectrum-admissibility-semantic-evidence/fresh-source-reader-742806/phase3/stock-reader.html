Complete source statement and conditions

Every actual cosine-grid precision lies between the identity and κ times the identity and is positive definite. I_d\preceq A\preceq\kappa I_d,\qquad A\succ0. \(d\in\mathbb N,\ d\ge2,\ \kappa\in\mathbb R,\ \kappa\ge2\). Fix any actual \(O\in O(d)\), including either determinant sign. The assertion holds pointwise; no Haar law or private-randomness premise is needed. For source indices \(i=1,\ldots,d\), let \(\theta_i=(i-\tfrac12)\pi/d\), \(\lambda_i=(\kappa+1)/2+(\kappa-1)\cos\theta_i/2\), and \(A=O\operatorname{diag}(\lambda_i)O^\top\). Lean uses zero-based \(i.\mathrm{val}+1/2\); the focused Test proves that index alignment. Matrix order is quadratic-form order: \(I_d\preceq A\) means \(A-I_d\) is positive semidefinite, and \(A\preceq\kappa I_d\) means \(\kappa I_d-A\) is positive semidefinite. This does not require every entry to be nonnegative. The finite-support definition covers all real coordinate vectors. Positive definiteness, symmetry, scalar interval bounds and both orthogonality identities are produced or obtained from the source orthogonal-group input; none is a new public hypothesis. The dimension premise is retained exactly even though the cosine envelope works for every angle. Mathematical proof

Open a step to read its argument and formula.

1. Bound each actual diagonal value

Since κ≥2, its cosine coefficient is nonnegative. Multiply the standard bounds −1≤cos θᵢ≤1 by that coefficient to obtain the exact source interval, without a spectral-window premise.

\[\begin{aligned}\lambda_i-1&=\tfrac{\kappa-1}{2}(1+\cos\theta_i)\ge0,\\\kappa-\lambda_i&=\tfrac{\kappa-1}{2}(1-\cos\theta_i)\ge0.\end{aligned}\]
Corresponding Lean step

hcoef is derived from hκ; hvalue consumes Real.neg_one_le_cos, Real.cos_le_one and exact real arithmetic.

2. Form the two positive diagonal differences

Use the actual scalar differences as diagonal entries. Nonnegative diagonal entries make these two actual diagonal matrices positive semidefinite, including their symmetry.

\[D_-=\operatorname{diag}(\lambda_i-1)\succeq0,\qquad D_+=\operatorname{diag}(\kappa-\lambda_i)\succeq0.\]
Corresponding Lean step

hdiaglo/hdiaghi prove the actual matrix identities entrywise; hlow/hhigh call the canonical PosSemidef.diagonal fact on the proved scalar bounds.

3. Conjugate through the actual rotation

Use OOᵀ=I from full real orthogonality. Distributing the actual products identifies the two differences with conjugates of the proved positive diagonal matrices. Positive semidefiniteness is preserved under this actual conjugation.

\[\begin{aligned}A-I_d&=O D_-O^\top\succeq0,\\\kappa I_d-A&=O D_+O^\top\succeq0.\end{aligned}\]
Corresponding Lean step

hO, hstar and the distribution identities hloweq/hhigheq feed hAlo/hAhi via PosSemidef.mul_mul_conjTranspose_same.

4. Produce strict positivity

Add the positive identity matrix to the first semidefinite difference. Every nonzero vector has strictly positive identity quadratic form, so the actual precision is positive definite. This is an output consequence.

\[x\ne0\ \Longrightarrow\ x^\top A x=\|x\|_2^2+x^\top(A-I_d)x>0.\]
Corresponding Lean step

hpos combines the canonical PosDef.one and PosDef.posSemidef_add with hAlo, then cancels the subtracted identity.

theorem actual_precision_admissible {d : ℕ} (hd : 2 ≤ d)
    {κ : ℝ} (hκ : 2 ≤ κ)
    (O : Matrix.orthogonalGroup (Fin d) ℝ) :
    let θ : Fin d → ℝ := fun i => ((i.val : ℝ) + 1 / 2) * Real.pi / (d : ℝ)
    let A : Matrix (Fin d) (Fin d) ℝ :=
      (O : Matrix (Fin d) (Fin d) ℝ) *
        Matrix.diagonal (fun i => (κ + 1) / 2 + (κ - 1) / 2 * Real.cos (θ i)) *
        (O : Matrix (Fin d) (Fin d) ℝ).transpose
    A.PosDef ∧ (A - 1).PosSemidef ∧
      (κ • (1 : Matrix (Fin d) (Fin d) ℝ) - A).PosSemidef := by
  classical
  let θ : Fin d → ℝ := fun i => ((i.val : ℝ) + 1 / 2) * Real.pi / (d : ℝ)
  let diagonalValue : Fin d → ℝ := fun i =>
    (κ + 1) / 2 + (κ - 1) / 2 * Real.cos (θ i)
  let U : Matrix (Fin d) (Fin d) ℝ := O
  let L : Matrix (Fin d) (Fin d) ℝ := Matrix.diagonal diagonalValue
  let A : Matrix (Fin d) (Fin d) ℝ := U * L * U.transpose
  change A.PosDef ∧ (A - 1).PosSemidef ∧
    (κ • (1 : Matrix (Fin d) (Fin d) ℝ) - A).PosSemidef
  have hcoef : 0 ≤ (κ - 1) / 2 := by linarith
  have hvalue (i : Fin d) : 1 ≤ diagonalValue i ∧ diagonalValue i ≤ κ := by
    have hlo := mul_le_mul_of_nonneg_left (Real.neg_one_le_cos (θ i)) hcoef
    have hhi := mul_le_mul_of_nonneg_left (Real.cos_le_one (θ i)) hcoef
    dsimp only [diagonalValue]
    constructor <;> nlinarith
  have hO : U * U.transpose = 1 := by
    simpa only [U] using
      (Matrix.mem_orthogonalGroup_iff (n := Fin d) (R := ℝ)).mp O.property
  have hstar : U.conjTranspose = U.transpose := by
    ext i j
    simp
  have hdiaglo : Matrix.diagonal (fun i => diagonalValue i - 1) = L - 1 := by
    ext i j
    by_cases hij : i = j <;> simp [L, hij]
  have hdiaghi : Matrix.diagonal (fun i => κ - diagonalValue i) = κ • 1 - L := by
    ext i j
    by_cases hij : i = j <;>
      simp [L, hij, smul_eq_mul]
  have hlow : (Matrix.diagonal (fun i => diagonalValue i - 1)).PosSemidef :=
    Matrix.PosSemidef.diagonal (fun i => sub_nonneg.mpr (hvalue i).1)
  have hhigh : (Matrix.diagonal (fun i => κ - diagonalValue i)).PosSemidef :=
    Matrix.PosSemidef.diagonal (fun i => sub_nonneg.mpr (hvalue i).2)
  have hloweq : U * Matrix.diagonal (fun i => diagonalValue i - 1) * U.transpose =
      A - 1 := by
    dsimp only [A]
    rw [hdiaglo, Matrix.mul_sub, Matrix.sub_mul, Matrix.mul_one, hO]
  have hhigheq : U * Matrix.diagonal (fun i => κ - diagonalValue i) * U.transpose =
      κ • 1 - A := by
    dsimp only [A]
    rw [hdiaghi, Matrix.mul_sub, Matrix.sub_mul, Matrix.mul_smul,
      Matrix.mul_one, Matrix.smul_mul, hO]
  have hAlo : (A - 1).PosSemidef := by
    rw [← hloweq]
    simpa only [hstar] using hlow.mul_mul_conjTranspose_same U
  have hAhi : (κ • (1 : Matrix (Fin d) (Fin d) ℝ) - A).PosSemidef := by
    rw [← hhigheq]
    simpa only [hstar] using hhigh.mul_mul_conjTranspose_same U
  have hpos := Matrix.PosDef.posSemidef_add hAlo
    (Matrix.PosDef.one : (1 : Matrix (Fin d) (Fin d) ℝ).PosDef)
  exact ⟨by simpa only [sub_add_cancel] using hpos, hAlo, hAhi⟩
