We next express the joint half-turn operator 𝖧\mathsf{H} in the same block decomposition. It is defined in (A.9) and is a self-adjoint Markov contraction by Proposition A.2. Since 𝖧\mathsf{H} acts only on the xx-coordinate, while every function in ran⁡(𝖯)\operatorname{ran}(\mathsf{P}) depends only on yy, we have 𝖧𝖯=𝖯\mathsf{H}\mathsf{P}=\mathsf{P}. Self-adjointness also gives 𝖯𝖧=𝖯\mathsf{P}\mathsf{H}=\mathsf{P}. Set 𝖧⟂⁣⟂≔𝖯⟂​𝖧𝖯⟂:ℌ⟂→ℌ⟂\mathsf{H}_{\perp\perp}\coloneqq\mathsf{P}^{\perp}\mathsf{H}\mathsf{P}^{\perp}:\mathfrak{H}_{\perp}\to\mathfrak{H}_{\perp}. The identity 𝖯𝖧=𝖯\mathsf{P}\mathsf{H}=\mathsf{P} makes ℌ⟂\mathfrak{H}_{\perp} invariant under 𝖧\mathsf{H}, so 𝖧⟂⁣⟂\mathsf{H}_{\perp\perp} is its restriction to ℌ⟂\mathfrak{H}_{\perp}. It is therefore self-adjoint, and ‖𝖧⟂⁣⟂​g‖=‖𝖧​g‖≤‖g‖\|\mathsf{H}_{\perp\perp}g\|=\|\mathsf{H}g\|\leq\|g\| for g∈ℌ⟂g\in\mathfrak{H}_{\perp}. Consequently,

𝖧=𝖯+𝖧⟂⁣⟂,−I⪯𝖧⟂⁣⟂⪯Ion ℌ⟂.\mathsf{H}=\mathsf{P}+\mathsf{H}_{\perp\perp}\,,\hskip 20.00003pt-I\preceq\mathsf{H}_{\perp\perp}\preceq I\hskip 10.00002pt\text{on }\mathfrak{H}_{\perp}\,. (B.6)

Relative to ℌ=ℌ𝖯⊕ℌ⟂\mathfrak{H}=\mathfrak{H}_{\mathsf{P}}\oplus\mathfrak{H}_{\perp}, this decomposition has the block representation

𝖧=(Iℌ𝖯00𝖧⟂⁣⟂).\mathsf{H}=\begin{pmatrix}I_{\mathfrak{H}_{\mathsf{P}}}&0\\ 0&\mathsf{H}_{\perp\perp}\end{pmatrix}\,.

The Markov operator 𝖪\mathsf{K} induced by the transition kernel 𝒦\mathcal{K} therefore factors as

𝖪=𝖴⁡[ρ​𝖯+(1−ρ)​𝖧]=𝖴⁡[𝖯+(1−ρ)​𝖧⟂⁣⟂].\mathsf{K}=\mathsf{U}\bigl[\rho\mathsf{P}+(1-\rho)\mathsf{H}\bigr]=\mathsf{U}\bigl[\mathsf{P}+(1-\rho)\mathsf{H}_{\perp\perp}\bigr]\,. (B.7)

Accordingly, its block representation is

𝖪=(𝖴𝖯𝖯𝖴⟂𝖯∗𝖴⟂𝖯𝖴⟂⁣⟂)​(Iℌ𝖯00(1−ρ)​𝖧⟂⁣⟂).\mathsf{K}=\begin{pmatrix}\mathsf{U}_{\mathsf{P}\mathsf{P}}&\mathsf{U}_{\perp\mathsf{P}}^{*}\\ \mathsf{U}_{\perp\mathsf{P}}&\mathsf{U}_{\perp\perp}\end{pmatrix}\begin{pmatrix}I_{\mathfrak{H}_{\mathsf{P}}}&0\\ 0&(1-\rho)\mathsf{H}_{\perp\perp}\end{pmatrix}\,.

The diagonal factor in the block representation of 𝖪\mathsf{K} contracts ℌ⟂\mathfrak{H}_{\perp} but leaves ℌ𝖯\mathfrak{H}_{\mathsf{P}} unchanged. For an observable f∈ℌ𝖯f\in\mathfrak{H}_{\mathsf{P}}, contraction therefore relies on the ℌ⟂\mathfrak{H}_{\perp}-component 𝖴⟂𝖯​f\mathsf{U}_{\perp\mathsf{P}}f created by reflection. The next subsection estimates this component and the subsequent action of 𝖧⟂⁣⟂\mathsf{H}_{\perp\perp}.
