theorem actual_first_order_query {d : ℕ} (hd : 2 ≤ d)
    {κ : ℝ} (hκ : 2 ≤ κ)
    (O : Matrix.orthogonalGroup (Fin d) ℝ) :
    let θ : Fin d → ℝ := fun i => ((i.val : ℝ) + 1 / 2) * Real.pi / (d : ℝ)
    let A : Matrix (Fin d) (Fin d) ℝ :=
      (O : Matrix (Fin d) (Fin d) ℝ) *
        Matrix.diagonal (fun i => (κ + 1) / 2 + (κ - 1) / 2 * Real.cos (θ i)) *
        (O : Matrix (Fin d) (Fin d) ℝ).transpose
    let f : EuclideanSpace ℝ (Fin d) → ℝ := fun x =>
      (WithLp.ofLp x) ⬝ᵥ (A *ᵥ WithLp.ofLp x) / 2
    let query : EuclideanSpace ℝ (Fin d) → EuclideanSpace ℝ (Fin d) :=
      fun x => WithLp.toLp 2 (A *ᵥ WithLp.ofLp x)
    ∀ x : EuclideanSpace ℝ (Fin d),
      HasGradientAt f (query x) x ∧
      (f x, gradient f x) = (inner ℝ x (query x) / 2, query x)

Full assumptions and notation

All objects and hypotheses

  • \(d\in\mathbb N,\ d\ge2,\ \kappa\in\mathbb R,\ \kappa\ge2\). Fix any full real \(O\in O(d)\), allowing either determinant sign, and every \(x\in\mathbb R^d\).
  • For \(i=1,\ldots,d\), set \(\theta_i=(i-\tfrac12)\pi/d\), \(\lambda_i=(\kappa+1)/2+(\kappa-1)\cos\theta_i/2\), and \(A=A_\kappa=O\operatorname{diag}(\lambda_i)O^\top\). The Lean index \(j\in\mathrm{Fin}(d)\) represents \(i=j.\mathrm{val}+1\).
  • The potential is exactly \(f_A(x)=x^\top Ax/2\), with zero additive constant. The response is exact precision multiplication \(q_A(x)=Ax\), not covariance multiplication \(A^{-1}x\) or the primitive hidden-rotation response \(Ox\).
  • The proof produces actual Fréchet derivative existence at every point, then identifies Lean’s total \(\mathrm{gradient}\). Differentiability, symmetry, admissibility, a gradient certificate and reply correctness are not added assumptions.
  • The private consumer uses the same hidden \(O\) for \(A_2\) and \(A_\kappa\). It reconstructs \(g=(\kappa-1)A_2x-(\kappa-2)x\), then the actual pair \((\langle x,g\rangle/2,g)\). Reference \(2\) is the condition-number parameter. The selected direction has no reciprocal or inverse-reply premise.
  • This is pointwise in the latent matrix; the mathematical parameter \(O\) is not an algorithmic disclosure of the eigenbasis. Random seeds, Haar laws, adaptive transcripts, query budgets and sampling accuracy are outside this statement.

Notation and interpretation

\(q_A,H,A_2\)

Exact precision response, the same action as a continuous linear map, and the reference-2 precision using the same hidden rotation.

\[q_A(x)=Hx=Ax,\qquad A_\eta=O\operatorname{diag}\!\left(\tfrac{\eta+1}2+\tfrac{\eta-1}2\cos\theta_i\right)O^\top.\]

Mathematical proof

Open a step to read its argument and formula.

1. Obtain symmetry of the actual precision

Use the existing canonical admissibility result for this literal source matrix. Its positive-definite output supplies Hermitian symmetry internally; no regularity certificate is assumed.

\[A=A^\top,\qquad Hx:=Ax,\qquad \langle Hy,v\rangle=\langle y,Hv\rangle.\]
Corresponding Lean step

hA is the Hermitian projection of actual_precision_admissible hd hκ O. Mapping self-adjointness through Matrix.toEuclideanCLM gives hH. This one existing actual admissibility declaration is the sole direct ASTIS producer parent.

2. Identify the same Euclidean quadratic

The matrix action and the continuous linear map have identical coordinates. The ordinary coordinate dot product therefore agrees with the Euclidean inner product for the same potential.

\[q_A(x)=Hx,\qquad f_A(x)=\tfrac12\langle x,Hx\rangle.\]
Corresponding Lean step

hquery is the actual coordinate-preserving map identity. Matrix.inner_toEuclideanCLM and real ring algebra establish hf, without changing f or introducing an additive constant.

3. Differentiate the actual function

Differentiate the identity map and the continuous linear map, then the inner product and multiplication by one half. This directly constructs a Fréchet derivative.

\[Df_A(x)[v]=\tfrac12\bigl(\langle x,Hv\rangle+\langle v,Hx\rangle\bigr).\]
Corresponding Lean step

hraw uses hasFDerivAt_id, H.hasFDerivAt, the canonical inner-product derivative and const_mul. This is a derivative-existence proof, not an evaluation of a default gradient.

4. Use symmetry to obtain the genuine gradient

Symmetry makes the two derivative terms equal. The resulting derivative is exactly the Riesz functional associated with Hx, so the actual gradient exists and equals the response.

\[Df_A(x)[v]=\langle Hx,v\rangle,\qquad \operatorname{HasGradientAt}(f_A,Hx,x),\qquad \nabla f_A(x)=Hx.\]
Corresponding Lean step

hlin identifies the continuous linear derivative with toDual of Hx, using hH and real_inner_comm. hasGradientAt_iff_hasFDerivAt produces hgrad; hg.gradient identifies the total gradient only after existence.

5. Assemble the exact first-order reply

Combine the proved gradient with the coordinate value identity. The same actual precision response determines both entries of the first-order observation.

\[\bigl(f_A(x),\nabla f_A(x)\bigr)=\bigl(\tfrac12\langle x,q_A(x)\rangle,q_A(x)\bigr).\]
Corresponding Lean step

Prod.ext combines the actual value equality with hg.gradient. The exact original source signature and all binders remain unchanged.

6. Consume the actual reference-precision reply

In the focused Test, the existing same-rotation affine provider converts the actual A2 reply into the actual Aκ action. Substitute it into the new derivative and pair results, giving the genuine observation of the κ potential.

\[g=(\kappa-1)A_2x-(\kappa-2)x=A_\kappa x,\qquad \bigl(f_{A_\kappa}(x),\nabla f_{A_\kappa}(x)\bigr)=\bigl(\tfrac12\langle x,g\rangle,g\bigr).\]
Corresponding Lean step

The private Test actually invokes FixedSpectrumAffine.actual_affine_precision_query and the new actual_first_order_query. Its two direct kernel ASTIS parents are those exact canonical declarations. Only the forward affine output is consumed; no inverse/nonzero bridge, count assertion or extra producer premise is used.

theorem actual_first_order_query {d : ℕ} (hd : 2 ≤ d)
    {κ : ℝ} (hκ : 2 ≤ κ)
    (O : Matrix.orthogonalGroup (Fin d) ℝ) :
    let θ : Fin d → ℝ := fun i => ((i.val : ℝ) + 1 / 2) * Real.pi / (d : ℝ)
    let A : Matrix (Fin d) (Fin d) ℝ :=
      (O : Matrix (Fin d) (Fin d) ℝ) *
        Matrix.diagonal (fun i => (κ + 1) / 2 + (κ - 1) / 2 * Real.cos (θ i)) *
        (O : Matrix (Fin d) (Fin d) ℝ).transpose
    let f : EuclideanSpace ℝ (Fin d) → ℝ := fun x =>
      (WithLp.ofLp x) ⬝ᵥ (A *ᵥ WithLp.ofLp x) / 2
    let query : EuclideanSpace ℝ (Fin d) → EuclideanSpace ℝ (Fin d) :=
      fun x => WithLp.toLp 2 (A *ᵥ WithLp.ofLp x)
    ∀ x : EuclideanSpace ℝ (Fin d),
      HasGradientAt f (query x) x ∧
      (f x, gradient f x) = (inner ℝ x (query x) / 2, query x) := by
  classical
  dsimp only
  let θ : Fin d → ℝ := fun i => ((i.val : ℝ) + 1 / 2) * Real.pi / (d : ℝ)
  let A : Matrix (Fin d) (Fin d) ℝ :=
    (O : Matrix (Fin d) (Fin d) ℝ) *
      Matrix.diagonal (fun i => (κ + 1) / 2 + (κ - 1) / 2 * Real.cos (θ i)) *
      (O : Matrix (Fin d) (Fin d) ℝ).transpose
  let f : EuclideanSpace ℝ (Fin d) → ℝ := fun x =>
    (WithLp.ofLp x) ⬝ᵥ (A *ᵥ WithLp.ofLp x) / 2
  let query : EuclideanSpace ℝ (Fin d) → EuclideanSpace ℝ (Fin d) :=
    fun x => WithLp.toLp 2 (A *ᵥ WithLp.ofLp x)
  let E := EuclideanSpace ℝ (Fin d)
  let H : E →L[ℝ] E := Matrix.toEuclideanCLM (𝕜 := ℝ) (n := Fin d) A
  -- The actual family's existing canonical producer supplies symmetry.
  have hA : A.IsHermitian :=
    (FixedSpectrumAdmissibility.actual_precision_admissible hd hκ O).1.1
  have hself : IsSelfAdjoint A := hA
  have hH : H.IsSymmetric :=
    ContinuousLinearMap.isSelfAdjoint_iff_isSymmetric.mp
      (hself.map (Matrix.toEuclideanCLM (𝕜 := ℝ) (n := Fin d)))
  have hquery (x : E) : query x = H x := rfl
  have hf : f = fun y : E => (1 / 2 : ℝ) * inner ℝ y (H y) := by
    funext y
    dsimp only [f]
    rw [show inner ℝ y (H y) = (WithLp.ofLp y) ⬝ᵥ (A *ᵥ WithLp.ofLp y) from
      Matrix.inner_toEuclideanCLM A y y]
    ring
  -- Differentiate the actual function and identify its Riesz functional.
  have hgrad (y : E) : HasGradientAt f (H y) y := by
    have hraw := ((hasFDerivAt_id y).inner ℝ H.hasFDerivAt).const_mul (1 / 2 : ℝ)
    have hlin : (1 / 2 : ℝ) •
        ((fderivInnerCLM ℝ (y, H y)).comp ((ContinuousLinearMap.id ℝ E).prod H)) =
        toDual ℝ E (H y) := by
      ext v
      change (1 / 2 : ℝ) * (inner ℝ y (H v) + inner ℝ v (H y)) = inner ℝ (H y) v
      rw [← hH.apply_clm y v, (real_inner_comm v (H y)).symm]
      ring
    apply hasGradientAt_iff_hasFDerivAt.mpr
    rw [hf, ← hlin]
    exact hraw
  intro x
  have hg : HasGradientAt f (query x) x := (hquery x).symm ▸ hgrad x
  refine ⟨hg, Prod.ext ?_ hg.gradient⟩
  change f x = inner ℝ x (query x) / 2
  rw [hquery]
  exact congrArg (fun t : ℝ => t / 2) (Matrix.inner_toEuclideanCLM A x x).symm
