
4 Proof of the W2 guarantee
In this section, our goal is to prove the W2 guarantee (Theorem 1.1). However, since we will later need to obtain stronger moment estimates for Theorem 1.2, we will first develop the part of the analysis that is common to both results.
4.1 Setup and smoothing estimates
For a positive-definite matrix M, write
Wq,M​(P,Q)≔infX∼P,Y∼Q(𝔼​∥X−Y∥Mq)1/q,∥x∥M≔(x𝖳​M​x)1/2.
Recall that
πη≔π∗𝖭⁡(0,η​I),Πη​(d​x​d​p)≔πη​(d​x)​𝖭​(0,I)​(d​p).
Let X|Y=y be drawn from Rη,y.

Lemma 4.1 (Hessian bounds for the smoothed potential).
For 0<η⩽1,
1κ+η​I⪯∇2Vη⪯11+η​I⪯I.
In particular gη is 1-Lipschitz.
Proof.
The RGO potential has Hessian between
(κ−1+η−1)​I and (1+η−1)​I. The
Brascamp–Lieb covariance inequality [13] gives
Cov⁡(X∣Y=y)⪯(κ−1+η−1)−1​I.
For the reverse bound, the
Cramér–Rao inequality (see, e.g., [24, Theorem 3.5.8]) gives
Cov⁡(X∣Y=y)⪰(1+η−1)−1​I.
Substitute both bounds in

∎
The following is the key estimate that decomposes the stochastic gradient error into a bias term and a stochastic error term.

∎
We will also need high-order regularity of the smoothed potential. The key
point is a near-Gaussian cancellation, which is stronger than the generic moment bound for a
strongly log-concave law. The Gaussian cumulant estimates used in the proof
are collected in Appendix C.

∎
4.2 Local error analysis
The W2 proof will be based on the local error framework.
Lemma 4.4 (Local error framework).
Let P,P^ be Markov kernels on ℝm. Suppose that, for every
x,y∈ℝm, there is a coupling
X∼δx​P, Y∼δy​P such that
∥X−Y∥L2⩽ρ⁡∥x−y∥,∥(X−x)−(Y−y)∥L2⩽χ⁡∥x−y∥.
(4.11)
Suppose also that, writing X^∼δx​P^,
W2​(δx​P^,δx​P)⩽ℰstrong,∥𝔼​X^−𝔼​X∥⩽ℰweak.

ℝm,
W22​(μ​P^,ν​P)⩽ρ​W22​(μ,ν)+ℰstrong2+(ℰweak+χ​ℰstrong)2ρ⁡(1−ρ).
Proof.
This is the standard local error theorem
[24, Lemma 5.1.2].
∎
We introduce three kernels and associated mappings.
• 
Let K^ denote the one-phase
kernel defined by Algorithm 3.1 with
stochastic gradients g^η. We can express the output of the phase as
Φ^z​(ζ,G) for Gaussian variables ζ, G.
• 
Define

• 
Finally, let K be the exact gradient numerical kernel obtained by
replacing every stochastic gradient g^η by gη. Write Φz for the corresponding map, so that
K⁡(z,⋅)≔(Φz)#​𝖭​(0,I2​d).
It is standard that contraction for HMC is only witnessed after a change of coordinates. Set
Mκ≔[12​κ+1212121]⊗Id.
Since κ⩾1, this defines a metric which is uniformly equivalent to the Euclidean norm; such twisted metrics are standard in the analysis of kinetic dynamics; see, e.g., [23, 30].
We apply the lemma after the linear change of coordinates
z↦Mκ1/2​z, with P≔K and
P^≔K^.
The structure of the proof is given by the following key theorem.
Theorem 4.5 (Local error analysis in W2).
Let J⩾2, and assume that h⩽c/(κ​log⁡J).
Then, for every phase-space law μ^,

Proof.
Fix z,z′∈ℝ2​d and set

Since J⩾2 and
ΛJ⩽C​log⁡(J+1)⩽C​log⁡J, the assumption on h implies

Those results verify (4.11) with
(Z,Z′) in place of (X,Y). We can bound

The three errors ℰbias, ℰvar, and ℰdisc correspond,
respectively, to the bias and centered fluctuation of the stochastic gradient
phase and to the discretization error of the numerical kernel. Thus, the
main task is to bound these errors.

4.4 Local error bounds
4.4.1 Bias bound
We first control the displacement between the conditional mean and
exact gradient kernels. Put
g¯η​(y)≔𝔼​g^η​(y,G)=gη​(y)+bη​(y).

If h​ΛJ⩽1, then

Proof.
Fix z,ζ∈ℝ2​d and write

by (4.2). To distinguish the two
first Picard updates, let Xti[1] denote the iterate obtained with
the exact gradient gη, and let X^ti[1] denote
the iterate obtained with g^η. Taking the expectation over the first
stochastic gradient block,
X¯ti[1]−Xti[1]
≔𝔼[X^ti[1]∣ζ]−Xti[1]=−∑j∈[J]ωi,jbη(Xtj[0]).

estimate
maxj∈[J]⁡∥X¯tj[1]−Xtj[1]∥⩽h2​ΛJ2​B.
(4.18)

X^ti[1]−X¯ti[1]=−∑j∈[J]ωi,jξη(Xtj[0];Gj[0]).

In contrast, Lemma 4.11 uses the fact that Z is Gaussian, together with the fact that the difference f​(Z,G)−f¯​(Z) is conditionally centered, to obtain a second-order bound which depends quadratically on A and B.
The proof, given in
Section C.3, is based on heat flow interpolation and Gaussian integration by parts.
We remark that for the purpose of this paper, we only need the case E=ℝm.
Remark 4.12.
Related second-order estimates are known for centered perturbations
independent of the Gaussian variable being perturbed: see
[59, Lemma 1] for bounded perturbations on a one-dimensional
subspace, [52, Theorems 2.1 and 2.7] for more general Gaussian
convolution inequalities, and the Ingster–Suslina second moment method [32] for divergence bounds.

asymptotic decay of W2 under Gaussian smoothing.
These independent perturbation results do not apply directly when

accounts for this dependence.
With this in hand, we can now bound the variance term.
