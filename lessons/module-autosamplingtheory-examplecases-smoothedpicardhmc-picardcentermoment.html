    Second moments through the two Picard query layers

    AutoSamplingTheory.ExampleCases.SmoothedPicardHMC.PicardCenterMoment.picard_center_gradient_moment · theorem · Teaching coverage

    Read this first

    Mathematical statement

    Define the first Picard centers Y⁰_i=X+t_iP₀. The actual stopped gradient-descent proximal program constructs measurable exact proximal points p, stopping indices N and returned points q, with p(y)+eta∇V(p(y))=y, ‖q(y)−p(y)‖≤eps and an exact finite-interpreter return equation. Define Z⁰_j=∇V(q(Y⁰_j)+sqrt(eta)G_j) and Y¹_i=Y⁰_i−Σ_j omega_ij Z⁰_j. Then all three displayed squared-gradient fields are integrable and obey the following explicit bounds. Center moments are established internally as the dominators, but are not separate public conclusions.

    \[\begin{gathered}B=6M+3\varepsilon^2+3\eta d,\qquad \mathbb E\|\nabla V(Y_i^0)\|^2\le 2M,\\ \mathbb E\|Z_j^0\|^2\le B,\qquad \mathbb E\|\nabla V(Y_i^1)\|^2\le 4M+2S^2B.\end{gathered}\]

    Proof roadmap

    1. 1Control the first centers

      Because |t_i|≤1, expanding Y⁰_i−x*=(X−x*)+t_iP and using (a+b)²≤2a²+2b² gives an integrable pointwise dominator. The state premise can therefore be integrated before any gradient estimate is used.

    2. 2Use genuine smoothness to control gradients

      The upper Hessian bound and C² regularity yield a genuinely 1-Lipschitz gradient. Since ∇V(x*)=0, the gradient norm is bounded by distance to x*. This also supplies measurability, so domination gives integrability rather than merely a numerical inequality.

    3. 3Relate the actual approximate query to the exact prox

      The existing execution theorem returns the actual finite stopped iterate q together with ‖q−p‖≤eps. The exact proximal map p is nonexpansive: subtract its two optimality equations and pair with p(y)−p(z); monotonicity of ∇V makes the extra term nonnegative. As x* solves its own proximal equation, p(x*)=x*.

    4. 4Bound every random proximal-gradient query

      Apply the 1-Lipschitz gradient estimate after adding sqrt(eta)G_j, then use (a+b+c)²≤3(a²+b²+c²). Only the marginal second moment of G_j enters, so no independence or joint Gaussian construction is needed here.

    5. 5Propagate through the weighted second layer

      A weighted Cauchy–Schwarz inequality bounds the square of the finite update by its absolute row sum times the correspondingly weighted query moments. Integrating and using Σ_j|omega_ij|≤S yields S²B. Combining this update with the first-center bound, then using the gradient-distance inequality once more, gives the layer-1 result.

    Full assumptions and notation

    All objects and hypotheses

    • E is a finite-dimensional complete real inner-product space with its Borel sigma algebra. V:E→R is C², kappa≥1, and kappa⁻¹‖v‖²≤D²V(x)[v,v]≤‖v‖² for every x,v.
    • On an arbitrary probability space, X and the post-refresh momentum P₀ used by Algorithm 3.1 are measurable and E[‖X−x*‖²+‖P₀‖²]≤M, with the integrability stated separately. A future adapter must derive this from the repeated-chain state estimate and the refresh step. The point x* is a genuine minimizer witness through ∇V(x*)=0.
    • The finite node family satisfies |t_i|≤1. Each innovation G_j is measurable, has integrable squared norm and E‖G_j‖²≤dim(E). Independence between nodes, X, P and G is not required for this edge.
    • The integrated interpolation weights satisfy Σ_j|omega_ij|≤S. The step parameters obey 0<eta≤c<1 and eps>0, so the existing finite stopped proximal program applies.

    Mathematical proof

    1. Control the first centers

    Because |t_i|≤1, expanding Y⁰_i−x*=(X−x*)+t_iP and using (a+b)²≤2a²+2b² gives an integrable pointwise dominator. The state premise can therefore be integrated before any gradient estimate is used.

    \[\|Y_i^0-x_*\|^2\le2(\|X-x_*\|^2+\|P\|^2),\qquad \mathbb E\|Y_i^0-x_*\|^2\le2M.\]
    Corresponding Lean step

    hY0bound, hY0I and hY0int establish the pointwise inequality, Bochner integrability and integral bound in that order.

    2. Use genuine smoothness to control gradients

    The upper Hessian bound and C² regularity yield a genuinely 1-Lipschitz gradient. Since ∇V(x*)=0, the gradient norm is bounded by distance to x*. This also supplies measurability, so domination gives integrability rather than merely a numerical inequality.

    \[\|\nabla V(y)\|=\|\nabla V(y)-\nabla V(x_*)\|\le\|y-x_*\|,\qquad \mathbb E\|\nabla V(Y_i^0)\|^2\le2M.\]
    Corresponding Lean step

    The shared quadratic-regularization theorem produces hLip; hgrad, hgradI and hgradInt apply it without treating totalized fderiv as differentiability.

    3. Relate the actual approximate query to the exact prox

    The existing execution theorem returns the actual finite stopped iterate q together with ‖q−p‖≤eps. The exact proximal map p is nonexpansive: subtract its two optimality equations and pair with p(y)−p(z); monotonicity of ∇V makes the extra term nonnegative. As x* solves its own proximal equation, p(x*)=x*.

    \[\|p(y)-p(z)\|\le\|y-z\|,\qquad p(x_*)=x_*,\qquad \|q(y)-x_*\|\le\|y-x_*\|+\varepsilon.\]
    Corresponding Lean step

    hpLip and hpstar are proved from hall and strong-convex gradient monotonicity. The theorem deliberately does not call the older eta≤1/2 Lipschitz wrapper, because D.7 only assumes 0<eta≤c<1.

    4. Bound every random proximal-gradient query

    Apply the 1-Lipschitz gradient estimate after adding sqrt(eta)G_j, then use (a+b+c)²≤3(a²+b²+c²). Only the marginal second moment of G_j enters, so no independence or joint Gaussian construction is needed here.

    \[\|Z_j^0\|^2\le3(\|Y_j^0-x_*\|^2+\varepsilon^2+\eta\|G_j\|^2),\qquad \mathbb E\|Z_j^0\|^2\le6M+3\varepsilon^2+3\eta d=B.\]
    Corresponding Lean step

    hZbound gives the pointwise estimate; hZdomI and hZI make the integrability obligation explicit; hZint integrates it using the probability normalization.

    5. Propagate through the weighted second layer

    A weighted Cauchy–Schwarz inequality bounds the square of the finite update by its absolute row sum times the correspondingly weighted query moments. Integrating and using Σ_j|omega_ij|≤S yields S²B. Combining this update with the first-center bound, then using the gradient-distance inequality once more, gives the layer-1 result.

    \[\left\|\sum_j\omega_{ij}Z_j^0\right\|^2\le\left(\sum_j|\omega_{ij}|\right)\sum_j|\omega_{ij}|\|Z_j^0\|^2,\quad \mathbb E\left\|\sum_j\omega_{ij}Z_j^0\right\|^2\le S^2B,\quad \mathbb E\|\nabla V(Y_i^1)\|^2\le4M+2S^2B.\]
    Corresponding Lean step

    weighted_sum_norm_sq_le, hweighted, hsumSqI and hsumInt handle the finite sum; hY1I, hY1int and hgrad1I complete the second layer.
