    theorem AutoSamplingTheory.TechnicalLemmas.Measure.L2Expectation.expectation_apply_eq_integral Partial Not mapped

    - The `L²(pi)` expectation functional is exactly the Bochner integral of the chosen `Lp` representative. The equality is representative-safe because both sides are insensitive to `pi`-a.e. changes.

    theorem expectation_apply_eq_integral
    (pi : Measure α) [IsFiniteMeasure pi]
    (f : Lp ℝ 2 pi) :
    expectation pi f = ∫ x, f x ∂pi := by
  rw [expectation_apply_eq_inner, MeasureTheory.L2.inner_def]
  apply integral_congr_ae
  filter_upwards
      [Lp.coeFn_const (α := α) (μ := pi) (p := (2 : ℝ≥0∞)) (c := (1 : ℝ))]
      with x hx
  change inner ℝ (one pi x) (f x) = f x
  rw [show one pi x = (1 : ℝ) by simpa [one] using hx]
  simp
