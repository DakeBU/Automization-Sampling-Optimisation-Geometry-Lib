Independent blind reconstruction

Let E be a finite-dimensional real inner-product space, with its normed additive group structure and a measurable space whose sigma algebra is the Borel sigma algebra. Dimension zero is permitted. Let V:E -> R, alpha,beta in the nonnegative reals, and eta in R. Assume precisely the following displayed premises: alpha>0 after coercion to R; alpha<=beta; V is twice continuously Frechet differentiable; for every x,v in E the second Frechet derivative satisfies
  alpha*||v||^2 <= D(DV)(x)[v][v] <= beta*||v||^2;
eta>0; and beta*eta<=1. Here and below alpha,beta are coerced to R in real arithmetic. No trajectory, measurable selection, or further regularity assumption is supplied.

Use the following literal definitions. On Omega=R^N let P be the countable product of rate-one exponential measures on R, and put e_k(omega)=max(omega_k,0), regarded as a nonnegative real. For y,r in E define c=y-eta*gradient V(r). For z=(q,p) in E x E and s in R set
  Phi(y,r,s,z)=(c+cos(s)*(q-c)+sqrt(eta)*sin(s)*p,
                  -sin(s)/sqrt(eta)*(q-c)+cos(s)*p).
Writing d=gradient V(q)-gradient V(r), set
  S(r,z)=(q,p-(2*<p,d>/||d||^2)*d),
  rate(r,z)=sqrt(eta)*max(0,<p,d>).
Scalar multiplication is real scalar multiplication. Real division is totalized: division by zero is zero, so this displayed reflection fixes z when d=0. The eta premise makes sqrt(eta) strictly positive in the flow formula.

For nonnegative t define the integrated rate along the free flow by
  Lambda(y,r,z,t)=integral from 0 to (t:R) of rate(r,Phi(y,r,s,z)) ds.
For a nonnegative threshold e let tau(y,r,z,e) be the infimum, in the nonnegative reals with an added top element, of times t>=0 with Lambda(y,r,z,t)-e>=0. The hit includes time zero. If there are no such times tau=top. The definition uses hittingAfter at initial time zero, rather than a strictly positive first hit.

The record space is the disjoint union (R_nonnegative x (E x E)) + Unit. A finite record (T,z) updates at threshold e to the absorbing stopped record if tau(y,r,z,e)=top. Otherwise it updates to
  (T+tau(y,r,z,e), S(r,Phi(y,r,(tau(y,r,z,e):R),z))).
The finite value of tau is obtained with untopD 0; that operation returns zero at top, but the guard takes the stopped branch there. A stopped record remains stopped. Start R_0=(0,z0), and define R_(n+1) from R_n using threshold e_n. Thus update n uses coordinate n; the zeroth record is before any update. Define T_n as its accumulated finite time when R_n is finite, and as top otherwise. For each omega all R_n and T_n in the conclusions use the threshold sequence e(omega).

There exists a SINGLE total function
  Z:E -> E -> (E x E) -> R_nonnegative -> Omega -> (E x E)
with all the following properties simultaneously.

(1) Z is jointly measurable in all its arguments. More exactly, the uncurried map on (((E x E) x (E x E)) x (R_nonnegative x Omega)) sending (((y,r),z0),(t,omega)) to Z(y,r,z0,t,omega) is measurable in the given product structures.

(2) For EVERY y,r,z0,omega,t,n and finite record a=(T,z), if
  T_n <= t < T_(n+1) and R_n=inl(a),
then
  Z(y,r,z0,t,omega)=Phi(y,r,(t-T:R),z).
The comparisons occur in WithTop(R_nonnegative), with t embedded as a finite value. Subtraction t-T is nonnegative-real subtraction max(t-T,0). This clause is universal even for exceptional sequences.

(3) For EVERY y,r,z0,omega,t, if there is NO index n with T_n<=t<T_(n+1), then Z(y,r,z0,t,omega)=z0. This is a prescribed total fallback, not an extra sample-path assumption.

(4) For EVERY fixed y,r,z0, for P-almost every omega, the following two conclusions hold together: for EVERY nonnegative t there exist n and a=(T,z) such that
  T_n<=t<T_(n+1), R_n=inl(a), T<=t,
  ((t-T):WithTop(R_nonnegative)) < tau(y,r,z,e_n(omega)),
  Z(y,r,z0,t,omega)=Phi(y,r,(t-T:R),z);
and Z(y,r,z0,0,omega)=z0.
The almost-everywhere quantifier precedes the universal time quantifier: one full-measure set works for all t for each fixed y,r,z0. It is not a single full-measure set asserted simultaneously for all y,r,z0. The interval is closed at the current event time and open at the next event time. The elapsed-time inequality against the next waiting time is strict. This asserts coverage at every finite time almost surely for each fixed initial tuple.

(5) For EVERY fixed y,r,z0 and EVERY nonnegative t, the free-flow defect event
  D_t={omega: Z(y,r,z0,t,omega) != Phi(y,r,(t:R),z0)}
is measurable and satisfies
  P.real(D_t) <= 1-exp(-Lambda(y,r,z0,t)).
The right-hand side uses the cumulative rate of the ORIGINAL initial state along its free flow. This is an upper bound on inequality with the free-flow state, not a claim identifying that event with an event-count condition or giving equality of probabilities.

(6) For EVERY fixed y,r,z0 and EVERY real delta>0, the events
  A_(delta,t)={omega: delta<=||Z(y,r,z0,t,omega)-z0||}
are measurable for ALL nonnegative t, and
  lim_(t -> 0 within R_nonnegative) P.real(A_(delta,t))=0.
The norm is the product norm on E x E. The event uses the non-strict comparison delta<=norm, and delta is any strictly positive real, not merely a nonnegative-real binder or a single chosen threshold. The limiting filter is the ordinary nonpunctured neighborhood filter of zero on the nonnegative real line, and the target filter is the ordinary real neighborhood filter of zero. Hence the conclusion is small-time convergence in probability to the initial state, including the time-zero value in the approach domain. It does not assert almost-sure path continuity or any moment convergence.

All structural definitions are fixed before the existential witness. The witness may depend on E and its structures, V, alpha, beta, eta and the supplied hypotheses; its displayed arguments expose y,r,z0,t,omega. There is no free constant in either probability conclusion and no hidden time rescaling: the displayed trigonometric flow uses s itself, with sqrt(eta) in its velocity-position coupling and rate. The conclusions are pointwise in y,r,z0 and delta, with no uniform parameter limit or common exceptional set across initial tuples asserted.

Conventions and truth boundary: P is the specified canonical product measure, not an arbitrary noise law. Negative and zero sample coordinates are totalized by toNNReal and remain covered by the universal clauses even though the almost-everywhere claims use P. The stopped record carries no state at infinity. Potential zero waiting times and missing finite interval coverage are addressed by the literal recurrence and total fallback; no strict positivity of every waiting time is assumed. The only input evidence of Lean compilation is the packet's compiled=true flag. This reconstruction makes no comparison with any original source and gives no source-fidelity or verification verdict.
