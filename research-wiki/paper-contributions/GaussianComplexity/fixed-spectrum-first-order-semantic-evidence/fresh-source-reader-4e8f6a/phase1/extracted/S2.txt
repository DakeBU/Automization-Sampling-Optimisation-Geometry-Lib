Targets and oracle.
[S2.SS0.SSS0.Px1.p1; HTML line 657]
[S2.SS0.SSS0.Px1.p1.1; HTML line 658]
We restrict the target class to centered Gaussians.
This restriction removes the hardness of locating the target and isolates the difficulty of sampling with an unknown covariance.
For an integer $d\geq 1$ and a parameter $\kappa\geq 1$ , without loss of generality, we normalize the spectral bounds to $1$
and $\kappa$ by rescaling and consider
the precision class
[S2.Ex1; HTML line 663]
$\mathcal{A}_{d,\kappa}:=\left\{A\in\mathbb{R}^{d\times d}:A=A^{\top},\quad I_{d}\preceq A\preceq\kappa I_{d}\right\}.$
[S2.SS0.SSS0.Px1.p1.2; HTML line 670]
An input $A\in\mathcal{A}_{d,\kappa}$ specifies the quadratic
potential $f_{A}(x):=\frac{1}{2}x^{\top}Ax$ and the target distribution
$\pi_{A}:=N(0,A^{-1})$ .
At a point $x\in\mathbb{R}^{d}$ , the exact first-order oracle returns
[S2.E1; HTML line 674]
$\operatorname{FO}_{A}(x):=\bigl(f_{A}(x),\nabla f_{A}(x)\bigr)=\left(\frac{1}{2}x^{\top}Ax,Ax\right).$
(1)
[S2.SS0.SSS0.Px1.p2; HTML line 683]
[S2.SS0.SSS0.Px1.p2.1; HTML line 684]
On this class, exact first-order access is equivalent to exact
matrix–vector access.
Indeed, a first-order response contains $Ax$ , while a
matrix–vector response determines both the gradient $Ax$
and the function value $\frac{1}{2}\langle x,Ax\rangle$ .
Thus the exact value-and-gradient, gradient-only, and
matrix–vector query complexities coincide.
[S2.SS0.SSS0.Px2; HTML line 693]
Randomized algorithms.
[S2.SS0.SSS0.Px2.p1; HTML line 696]
[S2.SS0.SSS0.Px2.p1.1; HTML line 697]
A randomized algorithm chooses its queries and stopping decisions
as Borel functions of its internal randomness and previous oracle
responses, where the randomness is independent of the input.
Its output may be any $\mathbb{R}^{d}$ -valued Borel function of
the same information.
The algorithm has fixed query budget $T$ if it makes
at most $T$ queries for every admissible input and every
realization of its internal randomness.

Accuracy measures.
[S2.SS0.SSS0.Px3.p1; HTML line 710]
[S2.SS0.SSS0.Px3.p1.1; HTML line 711]
For probability measures $P$ and $Q$ on a common measurable space,
their total variation distance is
[S2.Ex2; HTML line 713]
$\operatorname{TV}(P,Q):=\sup_{B}|P(B)-Q(B)|=\frac{1}{2}\int|p-q|\,d\lambda,$
[S2.SS0.SSS0.Px3.p1.2; HTML line 720]
where the supremum ranges over measurable sets, and $p$ and $q$
are the densities of $P$ and $Q$ with respect to any common
dominating measure $\lambda$ .
In particular,
$|\mathbb{E}_{P}h-\mathbb{E}_{Q}h|\leq\operatorname{TV}(P,Q)$
for every measurable function $h$ taking values in $[0,1]$ .

Sampling accuracy and query complexity.
[S2.SS0.SSS0.Px4.p1; HTML line 731]
[S2.SS0.SSS0.Px4.p1.1; HTML line 732]
For a fixed input $A$ , let $\rho_{A}^{\mathrm{Alg}}$ denote
the law of the algorithm’s output, with all internal
randomness included.
For $0<\varepsilon<1$ , define
[S2.E2; HTML line 736]
$Q_{G}(d,\kappa,\varepsilon):=\inf\left\{T\in\mathbb{Z}_{\geq 0}:\begin{array}[]{l}\exists\,\mathrm{Alg}\text{ with fixed query budget }T\\[2.0pt]
\text{such that }\displaystyle\sup_{A\in\mathcal{A}_{d,\kappa}}\operatorname{TV}\bigl(\rho_{A}^{\mathrm{Alg}},\pi_{A}\bigr)\leq\varepsilon\end{array}\right\}.$
(2)
[S2.SS0.SSS0.Px4.p1.2; HTML line 746]
The accuracy requirement is uniform over inputs and concerns
the output law after averaging over the algorithm’s seed.
Throughout the paper, query budgets are deterministic caps
on the number of queries in each run, rather than bounds
on the expected number of queries.
