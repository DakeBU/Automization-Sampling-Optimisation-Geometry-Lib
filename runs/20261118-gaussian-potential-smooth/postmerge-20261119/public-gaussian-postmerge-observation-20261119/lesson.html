    Smooth Gaussian polynomial data potentials

    Read this first

    Mathematical statement

    Let E be a finite-dimensional real inner-product space and let (X,Y) have joint probability law P, with X standard Gaussian and Y square integrable. For any real polynomial p and any probability rho on the unit sphere S, define the predictor and actual data potential by the integrals below. The potential V_rho is smooth on all of E. For every real radius R and derivative order n, there is a finite nonnegative constant C, chosen before rho and w, that bounds the norm of D^n V_rho(w) for every sphere probability rho and every ambient w with norm at most R.

    \[\begin{gathered}V_\rho\in C^\infty(E;\mathbb R)\quad(\rho\in\mathcal P(S)),\\\forall R\in\mathbb R\ \forall n\in\mathbb N\ \exists C\ge0:\\\forall\rho\in\mathcal P(S)\ \forall w\in E,\\\|w\|\le R\ \Longrightarrow\ \|D^nV_\rho(w)\|\le C.\end{gathered}\]

    theorem gaussian_polynomial_joint_potential_smooth_uniform_derivatives
    {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E]
    [FiniteDimensional ℝ E] [MeasurableSpace E] [BorelSpace E]
    (P : Measure (E × ℝ)) [IsProbabilityMeasure P]
    (hGaussian : P.map Prod.fst = stdGaussian E)
    (p : Polynomial ℝ) (hlabel : MemLp (fun z : E × ℝ => z.2) 2 P) :
    let S := {w : E // ‖w‖ = 1}
    let V : Measure S → E → ℝ := fun ρ w =>
      2 * ∫ z : E × ℝ,
        ((∫ v : S, p.eval ⟪(v : E), z.1⟫_ℝ ∂ρ) - z.2) *
          p.eval ⟪w, z.1⟫_ℝ ∂P
    (∀ ρ : Measure S, IsProbabilityMeasure ρ → ContDiff ℝ (∞ : ℕ∞ω) (V ρ)) ∧
    ∀ (R : ℝ) (n : ℕ), ∃ C : ℝ, 0 ≤ C ∧
      ∀ ρ : Measure S, IsProbabilityMeasure ρ →
        ∀ w : E, ‖w‖ ≤ R → ‖iteratedFDeriv ℝ n (V ρ) w‖ ≤ C

    Exact module and namespace context

    A changing parameter distribution should not require a new spatial bound at every time. The proof keeps one smooth Gaussian feature map and controls every law-dependent residual by the same norm estimate.

    Full assumptions and notation

    All objects and hypotheses

    • E is a finite-dimensional real inner-product space with its Borel sigma algebra. No positive dimension is assumed; an empty sphere has no probability law to instantiate.
    • P is a probability on E times R whose first marginal is exactly the standard Gaussian on E. The label Y is in L2(P); no independence or higher label moment is assumed.
    • p is any real polynomial. No parity, coefficient normalization, prescribed degree cutoff or conditional teacher relation is assumed.
    • For each R and n, the bound C may depend on P, p, E, R and n, but is uniform over rho and w. Order zero is included; a negative radius gives an empty spatial condition.

    Notation and interpretation

    S and f_rho

    S is the unit sphere; f_rho is the sphere-averaged polynomial predictor.

    \[S=\{v\in E:\|v\|=1\},\qquad f_\rho(x)=\int_S p(\langle v,x\rangle)\,d\rho(v).\]
    V_rho

    The actual joint-data integral potential, evaluated at any ambient point w.

    \[V_\rho(w)=2\int_{E\times\mathbb R}(f_\rho(x)-y)p(\langle w,x\rangle)\,dP(x,y).\]
    D^n and its norm

    The iterated Frechet derivative and its multilinear operator norm. Smoothness is proved, so the total Lean operators are classical derivatives here. At order zero the norm is the absolute value of the potential.

    \[\|D^0V_\rho(w)\|=|V_\rho(w)|.\]
    H, F, ell and m_rho

    H is joint-data L2; F is the polynomial feature class, ell is the label class, and m_rho is the Bochner mean of the feature.

    \[\begin{gathered}H=L^2(P),\quad F(w)=[(x,y)\mapsto p(\langle w,x\rangle)],\\\ell=[Y],\qquad m_\rho=\int_S F(v)\,d\rho(v).\end{gathered}\]

    Mathematical proof

    Open a step to read its argument and formula.

    1. Pull the smooth Gaussian feature into joint-data L2

    The existing polynomial ridge theorem gives a smooth map into Gaussian L2. Pullback by the first coordinate is a linear isometry into H, because the input marginal is exactly Gaussian. Its image is the actual polynomial feature class F. The membership witnesses are proof-irrelevant; no response differentiation or extra response moment is used.

    \[F:E\longrightarrow L^2(P)\text{ is }C^\infty.\]

  have hmarg : MeasurePreserving (Prod.fst : E × ℝ → E) P (stdGaussian E) :=

    Lp.compMeasurePreservingₗᵢ ℝ Prod.fst hmarg
  have hF : ContDiff ℝ (∞ : ℕ∞ω) F := by
    have he : F = fun w => J ((hg w).toLp (fun x : E => p.eval ⟪w, x⟫_ℝ)) := by
      rfl
    rw [he]
    exact J.toContinuousLinearMap.contDiff.comp hgSmooth
    2. Identify the literal data potential

    The existing joint-feature representation supplies the integrability and the displayed identity for the actual double integral. For each law, pairing with its residual is a continuous linear functional. Composition with the smooth feature therefore proves ambient smoothness.

    \[\begin{aligned}L_\rho(h)&=2\langle m_\rho-\ell,h\rangle_H,\\V_\rho(w)&=L_\rho(F(w)).\end{aligned}\]

      V ρ = fun w : E => 2 * ⟪mean ρ - label, F w⟫_ℝ :=

  let L (ρ : Measure S) : Lp ℝ 2 P →L[ℝ] ℝ :=
    (2 : ℝ) • innerSL ℝ (mean ρ - label)
  have hVL (ρ : Measure S) (hρ : IsProbabilityMeasure ρ) : V ρ = L ρ ∘ F := by
    rw [hV ρ hρ]
    rfl
  refine ⟨fun ρ hρ => ?_, ?_⟩
  · rw [hVL ρ hρ]
    exact (L ρ).contDiff.comp hF
    3. Bound every residual uniformly over the parameter law

    Continuity of F on the compact unit ball gives a nonnegative bound B. Integrating its norm against a probability law bounds every feature mean by B. The label has one fixed finite L2 norm, so every residual and every pairing functional have the same bound.

    \[\begin{aligned}\|m_\rho\|_H&\le B,\\\|m_\rho-\ell\|_H&\le B+\|\ell\|_H,\\\|L_\rho\|&\le2(B+\|\ell\|_H).\end{aligned}\]
    Corresponding Lean step
      · obtain ⟨B, hB⟩ := (isCompact_closedBall (0 : E) 1).exists_bound_of_continuousOn
      hF.continuous.continuousOn
    have hB0 : 0 ≤ B := (norm_nonneg (F 0)).trans (hB 0 (by simp))
    have hMean (ρ : Measure S) (hρ : IsProbabilityMeasure ρ) : ‖mean ρ‖ ≤ B := by
      let := hρ
      have hbound : ∀ᵐ v : S ∂ρ, ‖F v.1‖ ≤ B :=
        Filter.Eventually.of_forall fun v => hB v.1 (by simpa using v.property.le)
      simpa only [mean, Measure.real, measure_univ, ENNReal.toReal_one, mul_one] using
        norm_integral_le_of_norm_le_const hbound
    have hL (ρ : Measure S) (hρ : IsProbabilityMeasure ρ) :
        ‖L ρ‖ ≤ 2 * (B + ‖label‖) := by
      have hr : ‖mean ρ - label‖ ≤ B + ‖label‖ :=
        (norm_sub_le _ _).trans (add_le_add (hMean ρ hρ) le_rfl)
      simpa only [L, norm_smul, Real.norm_of_nonneg (by norm_num : (0 : ℝ) ≤ 2),
        innerSL_apply_norm] using mul_le_mul_of_nonneg_left hr (by norm_num : (0 : ℝ) ≤ 2)
    4. Transfer compact bounds on every derivative

    For each R and n, continuity of the n-th feature derivative gives a finite nonnegative bound M on the compact closed ball. Continuous-linear composition multiplies this bound by the common residual-functional bound. The resulting C is independent of the parameter law and evaluation point. The same rule includes order zero.

    \[\begin{aligned}D^nV_\rho(w)&=L_\rho\circ D^nF(w),\\\|D^nV_\rho(w)\|&\le2(B+\|\ell\|_H)M_{R,n}.\end{aligned}\]
    Corresponding Lean step
        intro R n
    have hn : (n : ℕ∞ω) ≤ (∞ : ℕ∞ω) :=
      WithTop.coe_le_coe.mpr (le_top : (n : ℕ∞) ≤ ⊤)
    obtain ⟨C, hC⟩ := (isCompact_closedBall (0 : E) R).exists_bound_of_continuousOn
      (hF.continuous_iteratedFDeriv hn).continuousOn
    refine ⟨2 * (B + ‖label‖) * max C 0, by positivity, ?_⟩
    intro ρ hρ w hw
    rw [hVL ρ hρ]
    exact ((L ρ).norm_iteratedFDeriv_comp_left hF.contDiffAt hn).trans
      (mul_le_mul (hL ρ hρ) ((hC w (by simpa using hw)).trans (le_max_left _ _))
        (norm_nonneg _) (by positivity))
