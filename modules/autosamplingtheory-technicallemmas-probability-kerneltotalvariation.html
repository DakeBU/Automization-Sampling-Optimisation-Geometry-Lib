    - An eventwise probability discrepancy bound is preserved by a common Markov kernel. The hypothesis on the empty event already implies `0 ≤ δ`. All helper functions and integrability proofs are local; the conclusion concerns the actual kernel-composed measures, not an assumed integral-contraction premise.

    (μ ν : Measure A) [IsProbabilityMeasure μ] [IsProbabilityMeasure ν]
    (K : Kernel A B) [IsMarkovKernel K]

    (hδ : ∀ s, MeasurableSet s → |μ.real s - ν.real s| ≤ δ) :

      simpa only [Real.norm_eq_abs, abs_of_nonneg (hf0 x)] using hf1 x
