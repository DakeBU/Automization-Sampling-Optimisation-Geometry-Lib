# Weak marginal evolution

These original Samplinglib supplements use actual pushforwards of the supplied
random states. The exact compiler statements and full module bytes enter the
individual publication bindings. Lean 4.33.0 and the repository Mathlib pin
apply to every declaration.

| Result | Quantifiers and boundary |
| --- | --- |
| Continuity of the marginal law | Each time slice is measurable. Whole-path continuity holds on one full-probability event. First countability applies to the time topology. |
| Centered sample increment | The signed balance uses arbitrary real endpoints. Product integrability uses time first and restricts Lebesgue measure to the unordered half-open interval. Both endpoint observations and the centered residual are integrable. |
| Derivative at a fixed time | The field is jointly continuous, the state space compact and the probability-law curve weakly continuous. The balance holds locally on real time. The observable uses the same totalized integral on both sides. |
| Measurable coefficient along a progressive process | The coefficient is Borel and bounded at each state and horizon time. Strong progressiveness is global. Section integrability holds at every sample, and product membership uses sample first with an arbitrary extended exponent. |
| Marginal balance for a measurable generator | A centered sample identity holds almost surely for each nonnegative terminal time. The generator is jointly measurable and uniformly bounded over each finite time horizon. The expectation is absolutely continuous on finite nonnegative intervals and has the ordinary derivative almost everywhere on strictly positive time. |

The continuous compact-state integration theorem is an existing proof dependency
for the pointwise derivative result. The stochastic sample identities in the
balance theorems are explicit inputs.
