The key algorithmic idea of this paper is to pick a smoothing parameter η>0\eta>0 and to sample from the smoothed distribution πη\pi_{\eta} instead of the original target π\pi. If Law⁡(Y)≈πη\law(Y)\approx\pi_{\eta}, then we can recover a sample from π\pi via the RGO: for X∼Rη,YX\sim R_{\eta,Y}, we have Law⁡(X)≈π\law(X)\approx\pi.
