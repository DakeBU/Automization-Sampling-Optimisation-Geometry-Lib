Anonymous mathematical reconstruction

For every pair of natural numbers d,q (natural numbers include zero) satisfying
    2q + 1 < d,
make all of the following definitions within the scope of that pair d,q and that hypothesis.

Put n = q+1 as a natural number, and let r = n viewed as a real number. Thus the statement's let-bound r is real, while all index sets below have natural-number size n. Let
    D = {0,1,...,d-1},    K = {0,1,...,q}.
For each i in D, define
    θ_i = (i + 1/2)π/d.
Define the real vector t_i indexed by K by
    t_{i,0} = 1,
    t_{i,k} = sqrt(2) cos(k θ_i) for k in {1,...,q}.
The second range is empty when q=0. Define
    S_i = sum_{k=0}^q t_{i,k}^2
        = 1 + 2 sum_{k=1}^q cos^2(k θ_i),
and define the real n-by-n feature matrix F_i by
    (F_i)_{k,ℓ} = t_{i,k} t_{i,ℓ};
equivalently, F_i = t_i t_i^T.

Let N be the space of real matrices with both row and column index set K×K. An element of N is an n^2-by-n^2 matrix, with its paired indices retained explicitly. Let I_n be the identity on K, and I_{n^2} the identity on K×K. Set
    B = ((r+2)/d^2) sum_{i=0}^{d-1} S_i (I_n ⊗ F_i) in N,
    C = 2r(r+2)/d in R.
Every occurrence of d in a real denominator or coefficient means its real coercion.

Then the real matrix
    M = C I_{n^2} - B
is positive semidefinite. In full, M is symmetric and, for every real array
    x = (x_{a,k})_{(a,k) in K×K},
one has
    sum_{a,k,b,ℓ in K} x_{a,k} M_{(a,k),(b,ℓ)} x_{b,ℓ} >= 0.

Tensor ordering and the difference

The first coordinate of each paired index belongs to I_n and the second to F_i. Consequently,
    (I_n ⊗ F_i)_{(a,k),(b,ℓ)} = δ_{ab} t_{i,k} t_{i,ℓ},
    B_{(a,k),(b,ℓ)}
      = ((r+2)/d^2) δ_{ab} sum_{i=0}^{d-1} S_i t_{i,k} t_{i,ℓ},
    M_{(a,k),(b,ℓ)}
      = C δ_{ab} δ_{kℓ}
        - ((r+2)/d^2) δ_{ab} sum_{i=0}^{d-1} S_i t_{i,k} t_{i,ℓ}.
Here δ is the Kronecker delta. No flattening convention for paired indices is required or added. In a block arrangement grouped by a, B has n identical diagonal blocks and zero off-diagonal blocks.

An equivalent explicit form of the asserted quadratic-form inequality is: for every such x,
    ((r+2)/d^2)
      sum_{i=0}^{d-1} S_i sum_{a=0}^q
        (sum_{k=0}^q t_{i,k} x_{a,k})^2
    <= (2r(r+2)/d) sum_{a=0}^q sum_{k=0}^q x_{a,k}^2.
Thus the direction of the PSD difference is B <= C I_{n^2} in positive-semidefinite order.

Quantifiers, assumptions, scopes, endpoints, and dependencies

The literal quantified hypothesis is only that d,q are natural numbers and 2q+1<d. The proof parameter hq witnesses that inequality; it does not introduce an additional numerical parameter. All eight successive lets r, θ, t, S, feature, N, B, C are definitions under these quantifiers, not further assumptions and not independently chosen objects. The only final predicate is that C I_{n^2}-B is positive semidefinite. The real array x in the expanded reading is universally quantified through the meaning of positive semidefiniteness.

All finite sums cover the full indicated carriers: i=0,...,d-1, and each index of Fin(q+1) takes the values 0,...,q, including both endpoints. The natural-number hypothesis implies d>=2q+2>=2, so every division by d here has a strictly positive denominator. The angles run from θ_0=π/(2d) to θ_{d-1}=π-π/(2d), with step π/d; neither 0 nor π is a sampled endpoint.

The dimensions are n=q+1 for a feature matrix and n^2=(q+1)^2 for B, its identity, and the PSD difference. The exact prefactor of B is (q+3)/d^2, and the exact scalar bound is
    C = 2(q+1)(q+3)/d.
Both depend only on d and q. There are no implicit constants, asymptotic qualifications, auxiliary parameters, probability events, or exceptional index sets in this proposition. It does not assert that the displayed constant is optimal.

Elementary consequences, distinguished from literal assumptions

From the definitions, r>=1, r+2>0, S_i>=1, and F_i is symmetric positive semidefinite. Hence B is itself symmetric positive semidefinite; this is a deduction from its nonnegative weighted outer-product construction, not an additional hypothesis in the input. Together with the asserted conclusion this yields 0 <= B <= C I_{n^2}. Symmetry of M likewise follows already from the definitions, while the nonnegative quadratic-form condition is the substantive asserted bound.

Because (r+2)/d^2>0, the displayed quadratic-form inequality can equivalently be divided by that coefficient:
    sum_{i=0}^{d-1} S_i sum_{a=0}^q
      (sum_{k=0}^q t_{i,k} x_{a,k})^2
    <= 2rd sum_{a=0}^q sum_{k=0}^q x_{a,k}^2.
Equivalently, for A=sum_{i=0}^{d-1} S_i F_i, the assertion is A <= 2rd I_n. These are equivalent readings of the asserted conclusion, not independent input assumptions.
