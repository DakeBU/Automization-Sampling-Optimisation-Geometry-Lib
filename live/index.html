                    Local execution policy

                    The compiler service binds only to loopback, serializes compilation, limits request size and time, writes snippets only to a system temporary directory, and never modifies repository source. It is a developer tool, not a hardened public code-execution sandbox. Keep it behind the documented private preview path.

                    Packet handoff

                    Samplinglib is the public formal library and learning interface of Auto-Sampling-Theory-In-Sleep (ASTIS).

                    Contribute · Attribution · Build and maintenance · generated from Lean source, route metadata, and gate evidence.

                    Substantive Advance export

                    Reviewed candidates can be exported with an exact source anchor, theorem delta, truth boundary, frontier cell, DAG inputs, target declarations, owned files, and focused Lean checks. Export is a proposal only; independent verification and the single stabilization lane control admission to Samplinglib and the Underlying Lean Graph.
