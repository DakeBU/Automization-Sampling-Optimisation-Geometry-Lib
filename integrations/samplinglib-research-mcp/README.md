# Samplinglib Research Workspace MCP App

This read-only MCP App exposes the exact proof routes, assumptions, source
anchors, recursive-call ledgers, error ledgers, and compiled-support labels
generated by Auto-Sampling-Theory-In-Sleep.  Its widget lets a researcher view
the same structured workspace inside ChatGPT or another MCP Apps-compatible
host.

It does **not** execute Lean, modify the repository, or mark a theorem proved.
An AI explanation remains unverified; exact Lean compilation and independent
source-fidelity review remain separate ASTIS gates.

## Run

The website download already contains `data/research-workspaces.json`.

```bash
npm install
npm start
```

The server listens on `http://127.0.0.1:8787/mcp` by default.  Set `PORT` or
`ASTIS_WORKSPACE_DATA` to change the port or data file.  During development,
expose the server through an HTTPS tunnel and connect the resulting `/mcp` URL
from ChatGPT developer mode.  Follow the current official OpenAI MCP Apps
instructions rather than committing tunnel URLs or credentials:

https://developers.openai.com/plugins/build/app-quickstart

The tools are:

- `list_research_workspaces`
- `open_research_workspace`
- `get_proof_step`
- `export_verification_packet`

## No-server alternative

Each Samplinglib workspace download also contains `workspace.md`,
`workspace.json`, a standalone `workspace.html`, and the currently attached
ASTIS-owned Lean support modules.  Upload the Markdown and JSON files to a
ChatGPT/Codex conversation or open the HTML locally.  Ask the agent to preserve
the evidence boundary in those files.

To run Lean rather than merely discuss it, clone the full ASTIS repository and
use its pinned toolchain and `/live/` local verified mode.  The bundled support
modules are source evidence, not a standalone Lean project.
